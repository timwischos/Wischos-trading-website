# 客户一轮调查流程

适用于：新潜在客户档案处理，从原始研究文件或最小信息输入（公司名 + 联系人 + LinkedIn）到可执行外展状态。

---

## 第一步：读取原始文件 / 整理最小输入

**情况 A：有 AI 生成的调查 MD 文件**

提取以下信息（不下结论，只提取原始内容）：
- 公司名、地区、规模、成立年份
- 联系人姓名、职位
- 网站 / 邮箱 / LinkedIn（如有）
- 产品类型描述
- 是否有本地化限制声明

**情况 B：仅有公司名 + 联系人姓名（最小输入）**

在文件顶部标注：`原始信息最小化 — 需主动研究`

记录已知信息，后续步骤补全。

---

## 第二步：全网调查一 — 信息收集 + 梯队判断

**目的：搜集足够信息，做出梯队判断。**

### 2.1 官网访问

**有官网必须访问，不能仅依赖搜索摘要。**

用 WebFetch 访问官网首页 + About / Products / Contact 子页面。

重点提取：
- 产品分类（对照 Wischos 现有产品线）
- 行业协会会员资质（PPPC / SAGE / PPAI / ASI 等）
- About 页面（公司背景、创始人、服务定位、成立年份）
- 客户类型或案例
- 任何 "Canadian-made only" / "local artisan" / 本地化限制声明
- **采购/进口信号**：有无"we source from overseas / Asia / China"、外国品牌代理、进口产品语言、warehouse/distribution 描述
- **服务模式**：rush / same-day / local fulfillment（不兼容）vs. planned project / annual program / catalog order（兼容）
- **定价档次**：premium / curated / quality-first 语言（兼容）vs. cheapest / budget / value 语言（价格战风险）
- **服务客户类型**：corporate clients / enterprise / recognized brands（采购量大）vs. 纯本地小生意（体量天花板）
- **Catalog 下载**：官网有 Catalog 入口时直接下载；无入口时搜：`site:域名 filetype:pdf` 或 `site:域名 catalog OR brochure`。分析重点：金属类产品有多少、档次如何、有无品类空白对应 Wischos 产品线。
- **是否参加行业展会**（表明主动找供应商）：
  - WebSearch：`"公司名" PPAI OR ASI OR PPPC OR Insights-X exhibition OR fair OR trade show`
  - 有展会记录 → 标注"主动开发供应商中"，接触时机更好
  - 有 exhibitor list 记录 → 他们在主动找供应商，外展优先级提高

**官网调查完成后必须输出产品分析表（每行一个主要品类，不超过8行）：**

| 品类 | 材质 | 价格带（估） | 采购方式 | 有无金属 | Wischos对应SKU |
|---|---|---|---|---|---|
| | | | 本地装饰/进口现货/按需定制/未知 | 有/无/部分 | |

**商业模式标签**（选一个或多个）：目录驱动 / 项目制 / 库存现货 / 按需定制 / 混合

**终端客户主要行业**：[列出 1-3 个，如：科技/金融/矿业]

**金属品类空白**（若有）：[客户目录中缺失但 Wischos 可提供的品类，直接影响切入角度选择]

### 2.1.1 公司规模与稳定性验证

**目的：补充官网无法直接判断的规模和稳定性数据，在梯队判断前完成。**

**Similarweb — 流量规模 + 地理分布：**
- WebFetch：`similarweb.com/website/域名`
- 重点：月访客量（<10K = 微型；10K–100K = 中型；>100K = 成熟业务）、主要流量来源国
- 无数据（网站太小）→ 标注"流量数据不足，公司规模存疑"；梯队判断相应降一档
- 有数据 → 填入 Sheet 1「规模」字段备注

**Owler — CEO信息 + 公司规模估算 + 竞品：**
- WebSearch：`owler.com "公司名"` 或 `site:owler.com "公司名"`
- 提取：CEO/创始人姓名、员工数估算、年收入估算、竞品列表
- 与 LinkedIn 员工数对照验证（两者差距大时取较低值保守估计）
- 竞品列表 → 发现可类比的同类分销商，辅助判断客户所在生态

**Whois 稳定性判断（此处为稳定性分析，与 2.2 层次3 邮箱查找用途不同）：**
- WebFetch：`whois.domaintools.com/域名`
- 域名注册年份 = 公司最早留下数字足迹的时间
- <3年 → 标注"新兴公司，稳定性待验证"，降一档
- ≥5年 → 标注"存续时间较长"，稳定性加分
- 注册人用个人 Gmail → 辅助判断为小型公司；用企业邮箱 → 有一定规模

### 2.2 邮箱查找

**层次1 — 官网直取（最快）：**
1. WebFetch Contact / About / Footer 页面 → 提取所有邮箱

**层次2 — Google 搜索：**
2. 无个人邮箱时，WebSearch：
   - `"联系人姓名" "公司域名" email`
   - `site:公司域名 "@"`

**层次3 — Whois 查域名注册人（小公司常用个人邮箱注册域名）：**
3. WebSearch/WebFetch：`whois.domaintools.com/域名` 或 `whois.chinaz.com`
   → 查注册人姓名和联系邮箱

**层次4 — Wayback Machine 查历史页面（旧网站可能有未隐藏邮箱）：**
4. WebFetch：`web.archive.org/web/*/域名`，选 3–5 年前快照
   → 旧版 Contact/About 页面常有已删除员工邮箱
   → 组合搜索：`web.archive.org 公司名 founder OR owner email`

**层次5 — 网页源码挖邮箱（70–80% 命中率）：**
5. 打开目标公司官网 Contact 页面 → 右键查看页面源代码（Ctrl+U）
   → Ctrl+F 搜索 `@` 或 `mailto:` → 表单后台常有隐藏邮箱
   （**适用于真实浏览器环境；若工具无法 view-source，跳过此步**）

**层次6 — 邮箱格式推断：**
6. 工具：email-format.com → 输入公司域名 → 查该公司已知邮箱格式
   → 有任意员工邮箱 → 按格式推断决策人邮箱
   常见格式：`firstname@` / `first.last@` / `firstnamelastname@` / `f.last@`

**层次7 — LinkedIn / ZOOMINFO：**
7. WebSearch：`site:linkedin.com "公司名" "procurement" OR "sourcing" OR "buyer"`
   → Hunter.io 或 RocketReach（免费额度）输入域名补充验证

**找不到时备用：** 标注"邮箱待确认"，LinkedIn 通过后直接要：
> "Happy to send over a few specs — easiest by email. What's the best address?"

### 2.2.1 邮箱验证（优先级 ≥⭐⭐⭐⭐ 时必做）

找到邮箱后，发信前验证真实性，避免硬退信（hard bounce）损伤发件域名：

```
verify-email.org — 输入邮箱，实时验证是否存在
mailtester.com — 测试邮箱有效性
verifyemailaddress.org — 简单验证
```

- 验证结果"valid" → 可发
- 验证结果"unverifiable / risky" → 仍可发，但做好退信预案
- 验证结果"invalid" → 换层次再找，不发

### 2.3 联系人 LinkedIn 查找

**执行范围：原始文件列出的联系人 + 第2.1步官网团队页发现的所有决策级联系人，逐一执行。**

1. WebSearch：`"联系人全名" "公司名" site:linkedin.com`
2. 找 `linkedin.com/in/` 格式个人页（不是公司页）
3. 记录完整 URL，确认职位是否与原始文件一致
4. 找不到 → 标注"LinkedIn 待确认"

> 每位需接触的联系人都必须有 LinkedIn URL 记录（已确认 / 待确认），不得留空。

### 2.4 行业协会身份

- WebSearch：`"公司名" PPPC OR PPAI OR ASI OR SAGE OR BPMA member`
- 找到 → 记录协会名称、奖项 / 提名
- 注意：distributor 会员身份不限制他们从非会员供应商采购
- 各市场主要协会会员目录（可直接搜索已有客户）：
  - 加拿大 PPPC：pppc.ca/find-a-member/
  - 美国 ASI：asicentral.com
  - 英国 BPMA：bpma.co.uk/find-a-member/

### 2.5 客户 B2B 足迹检查（判断采购活跃度 + 现有供应商）

**目的：判断客户是否正在主动找供应商，以及他们当前的金属类供应商是谁。**

**检查采购询价足迹：**
```
WebSearch：alibaba.com + "公司名"
→ 是否在阿里发过询价/合作记录

WebSearch：made-in-china.com + "公司名"
→ 同上

WebSearch："公司名" + "send me pricelist" OR "looking for supplier" OR "request for quote"
→ 是否在公开论坛/行业网站发过采购需求
```

**逆查现有供应商（海关数据）— 梯队判断前必查，全部平台逐一执行：**

执行方式：每个平台用 WebFetch 直接访问，或 WebSearch `site:平台域名 "公司名"`  
**必须对每个平台单独记录结果（有记录 / 无记录 / 无法访问）。不得跳过任何一个。**

- [ ] importyeti.com
- [ ] customs.report
- [ ] 52wmb.com
- [ ] volza.com
- [ ] importgenius.com（Google搜 `site:importgenius.com "公司名"` 可免费看摘要）
- [ ] panjiva.com
- [ ] datamyne.com
- [ ] tradesns.com（贸立方）

**⚠️ 不得因客户所在国家预判平台覆盖范围而跳过。各平台均可能含有该国数据。搜了没结果才算无记录，没搜不算。**

查询重点：
- 是否从中国/亚洲供应商进货 → **有 = 熟悉进出口流程，接受中国供应商，切入阻力低；无 = 需评估是否有进口意愿**
- 货物描述中有无金属礼品类
- 供应商名称、产地、频次、体量

**判断意义（结果直接影响梯队评级）：**
- 有进口记录 + 金属类 → 有现有供应商；分析档次差距，找升级或补充空白切入点；**评级不因无公开足迹而降级**
- 有进口记录 + 无金属类 → 强烈信号：金属品类空白，切入理由最充分；**主动上调一档**
- 无进口记录 + 其他信号强 → 可能靠固定供应商或本地采购，需更具体切入理由；维持当前评级
- 无进口记录 + 其他信号弱 → 进口意愿存疑；**下调一档**

**注意：** importyeti 免费额度够基础查询；此步骤对所有通过 Triage 的客户执行，不设评级门槛。

### 2.6 梯队判断

基于以上调查结果，对照下表做判断：

| 梯队 | 客户类型 | 兼容性信号 | 开发策略 |
|---|---|---|---|
| **A — 主攻** | 直接终端买家（HR / Marketing / Procurement，科技 / 金融 / 矿业 / 法律 / 咨询） | 有年度礼品计划 / 大型企业 / 采购提前规划 | 最高优先，写 MD，写开发信 |
| **A — 主攻** | 激励与忠诚度计划公司（Incentive & Loyalty，如 ITA Group、O.C. Tanner、Reward Gateway） | 有持续项目、复购模式明确 | 最高优先，复购稳定，进入即锁定 |
| **A — 主攻** | 员工认可 SaaS 平台（进入平台 SKU = 自动持续复购） | 有在线目录、SKU上架机制 | 最高优先 |
| **B — 重点挑选** | 精品礼品代理（无自有中国金属供应链）/ APAC 礼品平台 | 官网无金属品类 / 有进口语言 / premium定位 | 挑规模合适的，写 MD；切入角度：填补金属品类空白 |
| **B — 重点挑选** | 活动管理公司（企业年会 / 峰会 VIP 礼品） | 有年度固定活动证据（官网案例 / 客户名单） | 挑有年度固定活动的；确认活动日期再评估交期 |
| **B — 重点挑选** | 豪宅房产（closing gifts，澳洲 / 新加坡 / UAE） | 高端楼盘 / 客单价高 / 中介本人决策 | 决策人是中介本人，链条短；推金属笔+桌面小件 |
| **C — 补充** | 本地 promo 门店（Fully Promoted 类）/ gift hampers 公司 | 有金属类但档次低 / 有进口经验 | 体量有限；切入角度：升级现有金属品质 |
| **C — 补充** | B2B 营销代理 / 大学校友会 / 医疗制药 HCP | 有特定项目需求 | 视项目而定，不投常规精力 |
| **排除** | 大型分销商（Dynamic Gift、Cubic Promote 类，有自己中国采购团队） | 官网写"in-house sourcing" / 员工100+ | 会压价绕过，不要开发 |
| **排除** | Local artisan / printing only / apparel only / non-profit fundraising | 无进口信号 / 明确本地制造声明 | 直接排除，不建档 |
| **降级信号** | 任何梯队客户，若官网显示 rush/same-day/local fulfillment 为核心卖点 | — | 降一级处理，标注"采购模式不兼容" |

> **梯队 A 或 B → 继续处理；梯队 C → 评估后选择性处理；排除 → 仅记入 CRM 备注列，不投精力。**

## 第三步：全网调查二 — 找接触钩子

**目的：为邀请信和跟进私信找到具体由头，不能用泛泛夸赞替代。**

### 3.1 联系人近期动态

- WebFetch 联系人 LinkedIn 个人页
- 找近期帖子（30天内）→ 记录主题
- 有 → 可用"Saw your post on..."开头，最具说服力
- 无 → 用行业共鸣代替（"Saw you work a lot with..."）

### 3.2 公司近期动态

- WebSearch：`"公司名" site:linkedin.com` → 查公司 LinkedIn 页最近帖子
- WebSearch：`"公司名" 2025 OR 2026 news award expansion`
- 找到获奖 / 新品 / 扩张 / 招聘 → 记录，可作邀请信钩子

### 3.3 公开客户案例 / 服务行业

- WebFetch 官网 Portfolio / Case Studies / Clients 页
- 判断主要服务行业 → 对照 Wischos 场景（科技 / 金融 / 矿业 / 医疗等）

**输出：** 列出 1–2 个具体接触钩子，写入客户档案"接触钩子"字段。

## 第四步：独立核查三个关键问题

不依赖原始文件的结论，独立判断：

**1. 产品是否实际匹配？**
- Wischos 产品范围：**所有金属相关礼品**均可采购或定制开发，不限于当前网站在售 SKU
- 对照客户需求，判断产品类型是否属于金属类：属于 → 保留推荐，标注"现有 SKU"或"可按需采购"
- 非金属类 / 完全无关品类（如纺织品、塑料品） → 标注"不推"
- 现有 SKU 参考：笔 / 桌面 / EDC / 饮品 / 套件；**不在当前网站的金属礼品**（如 lapel pins、medallions、awards、card cases、custom-shaped pieces 等）→ 标注"可按需采购，询盘后确认交期/报价"，保留在分析中

**按客户类型推荐产品切入角度：**

| 客户类型 | 切入角度 | 优先推荐产品 | 可扩展产品 |
|---|---|---|---|
| Promo distributor（目录无金属品类） | Category expansion — 填补金属礼品空白 | WGS套件全系 + 金属笔 + 桌面配件 | Lapel pins、奖牌、card cases（按需采购） |
| Promo distributor（有金属但档次低） | Premium upgrade — 升级材质与包装 | WGS-005/008（精工套件）+ 钛/黄铜笔 | 定制包装、礼盒方案 |
| 终端HR / Marketing | One-stop solution — 一次搞定选品+定制+交货 | WGS-005（Executive）/ WGS-006（Onboarding）/ WGS-008（Quartet） | 定制入职套件、年末礼品方案 |
| Awards / Recognition公司 | Custom metal recognition — 定制金属认可件 | 定制金属奖牌 / 刻字笔 / custom-shaped pieces | 年度认可计划套件 |
| Event Management | Planned VIP gifts — 有计划的活动礼品 | WGS套件 + 刻字金属饮品杯 | 定制活动纪念品 |
| 豪宅房产 | Closing gifts — 成交礼 / 客户维系 | 金属笔 + 名片夹 + 桌面小件 | Closing gift套件（定制） |
| Gift hamper公司 | Premium metal insert — 礼盒高档金属填充件 | 单品金属笔 / EDC / 小桌面件 | 定制套件作为整盒解决方案 |

> **外展话术原则**：内部分析中保留全部金属类可能性；写给客户的话术中，优先提有信心交货的现有品类，其余以"I can also develop custom metal pieces around your brief"兜底，不主动许诺具体 spec。

**2. 联系人是否有采购决策权？**

| 职位 | 决策力 | 外展角度 |
|---|---|---|
| Owner / Founder / Principal / President | 高 — 直接决策 | 谈供应商合作 |
| Procurement / Sourcing Manager / Head of Buying | 高 — 职能决策 | 谈供货方案 |
| Sales Manager / Account Manager（管多客户） | 中高 — 选品影响大 | "帮她赢得客户项目" |
| Account Manager（单一大客户） | 中 — 需确认建议权 | 先摸清决策链 |
| Marketing / Coordinator / Executive | 低 — 无决策权 | 必须找上级 |

**决策人不对时 → 主动查找实际决策人：**

1. WebFetch 公司 LinkedIn 页（公开员工列表）
2. WebSearch：`site:linkedin.com "公司名" "procurement" OR "sourcing" OR "buyer" OR "head of"`
3. WebFetch 官网 About / Team 页面
4. WebSearch：`"公司名" "procurement manager" OR "sourcing director" 联系方式`

找到后：将新联系人写入文件，原联系人标注"非决策层，备用"。**立即对新联系人执行第2.3步 LinkedIn 查找**，补全 LinkedIn URL + 邮箱推断。未找到则降低优先级评级一档。

**3. 是否存在结构性障碍？**
- Local artisan / Canadian-made only → 明示产地，主动筛选
- 公司规模过小 → 体量天花板，降低投入预期
- 固定供应商体系 → 进入难度高，需特殊切入角度

## 第五步：优先级评定

使用五星制（与总流程指南统一）：

| 评级 | 条件 |
|---|---|
| ⭐⭐⭐⭐⭐ | 经典 promo distributor + 无产地限制 + Owner 或高决策力联系人 + 产品高度匹配 |
| ⭐⭐⭐⭐ | 方向匹配 + 有一个结构性障碍（规模 / 职位 / 产地） |
| ⭐⭐⭐ | 方向部分匹配 / 两个结构性障碍 / 体量天花板明显 |
| ⭐⭐ | 仅类目交叉 / 难触达 / 决策链过长 |
| ⭐ | local artisan 硬限制 / 产品完全不匹配 → 不建档 |

**评级后决策：**
- ≥ ⭐⭐⭐⭐ → 建单客户档案（复制模板 Excel，9 sheet 全填）
- ⭐⭐⭐ → 仅入总 CRM 主表，备注列记录核心判断
- ≤ ⭐⭐ → 总 CRM 备查，不投精力

## 第六步：检查 LinkedIn 邀请信

原始文件的邀请信**几乎必超 300 chars**（LinkedIn 连接邀请上限）。必须重写。

重写原则：
- 总字数 ≤ 300 chars（含空格标点）
- 结构：[接触钩子] + [我是谁/做什么] + [Open to connecting?]
- 钩子优先用第三步找到的具体由头，不用泛赞
- 不用 "really" / "I'd love to" / "certainly" 等填充词
- 含产地（from China）→ 主动筛选，节省双方时间
- 产品举例只写 Wischos **实际有货**的品类

**字数验证**：写完后计数，确保 ≤ 300 chars。

## 第七步：写跟进私信

连接通过后发送的第一条私信，原则：
- 先认可对方近期动态（帖子 / 业务重点 / 近期活动）
- 若无近期动态，改用行业共鸣开头（"Saw you work a lot with hospitality clients..."）
- 简短说明供货能力，对应她的具体场景
- 结尾开放式提问（"happy to share a few items if useful"）
- 不附目录，不一次性推全产品线
- 不超过 5 句话

## 常见原始文件问题清单

| 问题 | 处理方式 |
|---|---|
| LinkedIn 邀请信超 300 chars | 必须重写，不能直接用 |
| 推荐产品 Wischos 无货（如 token / trophy） | 从外展文案中删除，标注"扩充后可推" |
| 评级过于乐观（忽略 local artisan / 职位层级） | 独立重新评级，写明降级原因 |
