目标：结合 SEO 与 GEO 审查结果，对 7 个套件的现有文案提出可执行修改方案。修改方向以“小幅增强”为主，不推倒重写，保留当前 B2B 采购视角和克制语气。

---

## 1. 总体修改策略

当前套件文案已经具备 B2B 采购阅读价值：产品组合清楚、材质与包装具体、Sourcing Notes 有采购视角。问题主要不在风格，而在“可搜索、可引用、可转化”的结构还不完整。

建议分两层修改：

1. **页面层新增内容**：用于 SEO/GEO 承接，包括定义块、Key Takeaways、套件对比表、选择指南、FAQ、Meta 信息和 schema。
2. **套件字段层微调**：用于改进每个套件的 Hero、Selling Points、Sourcing Notes、CTA 和风险表达。

不建议：

- 不要把所有套件改成营销型大词堆砌。
- 不要删掉 Sourcing Notes，目前这是 B2B 信任感的重要来源。
- 不要在正文加入价格、MOQ、交期承诺。
- 不要使用 `Buy now`、`Shop now`、`Add to cart` 等 C 端 CTA。

Wischos 定制金属企业礼品套件，是面向 B2B 批量采购的礼品组合，围绕实用金属工具、定制 logo 工艺和品牌礼盒包装构建。套件覆盖桌面礼品、日常随身套件、现场团队工具、入职欢迎套件和高管桌面礼品。

## 3. 全局字段修改规则

以下规则应应用到 7 个套件文案中。

### 3.1 补齐 CTA

WGS-001、WGS-002、WGS-003 当前缺 CTA，需要补齐，保持与后四套一致。

### 3.2 每套增加一个可引用定义句

建议每套在 Hero Copy 后增加 `Definition` 或 `Best for` 字段。这个字段不一定在前端显式命名为 Definition，也可以作为套件副描述使用。

### 3.3 增加 SEO 场景词，但每套只加 1-2 个

不要堆词。建议每套 Hero 加一个主场景词：

| 套件 | 建议加入关键词 |
|---|---|
| WGS-001 | custom desk gift set / branded desk set |
| WGS-002 | custom executive desk gift set |
| WGS-003 | branded everyday carry gift set / EDC corporate gift set |
| WGS-004 | field team gift set / utility corporate gift set |
| WGS-005 | branded daily carry gift set / custom executive gift set |
| WGS-006 | employee onboarding gift set / welcome kit |
| WGS-007 | executive desk gift set / client appreciation gift set |

### 3.4 降低强 claim 风险

必须修改或核实：

| 当前表达 | 建议处理 |
|---|---|
| `writes up to 20,000m` | 有供应商规格则写 `supplier-rated`；无依据则改成 `designed for long writing life` |
| `no movement in transit` | 改成 `helps reduce movement in transit` |
| `does not peel` | 改成 `resists peeling under normal handling` |
| `At this price tier` | 删除价格层级表达 |
| `pure titanium` | 核实是否纯钛；如为钛合金需改写 |
| `RFID aluminium badge holder` | 明确是 RFID blocking 还是 access-card holder |
| `glass breaker` | 加入 workplace policy / permitted context 限定 |

### 3.5 术语统一

| 当前表达 | 建议表达 |
|---|---|
| `你的 logo` | `品牌 logo` |
| `company value` | `brand message` |
| `company values` | `brand messages` 或 `company values`，按场景选择 |
| 高频 `built for` | 穿插 `designed for`、`selected for`、`suited to` |
| `Sourcing Note` | 可保留；如前端面向采购者，可考虑 `Buyer Note` 或 `Why This Set Works` |

## 6. Schema 与结构化数据建议

### 6.1 集合页

使用：

- `ItemList`
- `FAQPage`

`ItemList` 用于列出 7 个套件；`FAQPage` 必须与页面可见 FAQ 一致。

### 6.2 套件详情页

如每个套件有独立页面，可以使用 `Product` schema。

注意：

- 不要写虚假 `aggregateRating`。
- 不要写没有依据的 `review`。
- 不要写固定价格，除非页面明确展示价格。
- B2B 询价型页面可以避免写具体 `Offer`，或只在技术上保留询价逻辑。

## 8. 最终判断

这组文案不需要重写，需要“结构补强 + 风险降级 + 场景词补位”。

最关键的修改是：

1. **把 WGS-006 明确打造成 employee onboarding gift set。**
2. **把 WGS-002 和 WGS-007 明确打造成 executive / client appreciation desk gift sets。**
3. **把 WGS-003 和 WGS-005 明确打造成 everyday carry / commute-to-desk gift sets。**
4. **把 WGS-004 保持为 field team / utility gift set，但降低安全工具合规风险。**
5. **页面层增加定义块、对比表、FAQ 和 schema，让 AI 能稳定抽取。**

按这个方向改，既能保持当前 B2B 采购语气，也能补足 SEO 搜索承接和 GEO AI 引用能力。
