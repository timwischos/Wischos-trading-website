## 二、需要修改的部分

### 问题1：Sourcing Notes 标题系统性问题（14条）

**问题描述：**
7套合计14条 Sourcing Notes 标题使用 "Why X works / Why X belongs / Why X fits" 格式。这类句式的潜台词是"我来告诉你为什么这个选择是对的"，属于销售员在说服买家，不符合原则8要求的"行内采购人视角"。

采购行内人不解释立场，直接陈述认知。标题改为陈述句后，正文语气自然跟着校正。

**修改清单：**

| 套件 | 原标题 | 建议改为 |
|---|---|---|
| WGS-001 | Why inkless works for gifting | Inkless pen: consumables reduction and gifting logic |
| WGS-001 | Why a letter opener still belongs on a desk | Letter opener: desk function and daily visibility |
| WGS-002 | Why the propeller opener belongs in the set | Propeller letter opener: mechanism and desk use context |
| WGS-002 | Brass as a desk material | ✅ 保留（已是陈述式） |
| WGS-003 | Why three metals in one set | Material allocation across three carry functions |
| WGS-003 | Why this set works across teams | Mixed-team carry: why daily-carry items fit different roles |
| WGS-004 | Why these three tools belong together | Field tool selection logic: writing, prying, cutting |
| WGS-004 | Why this set fits field-facing industries | Field-facing use context: construction, logistics, maintenance |
| WGS-005 | Why titanium fits this set | Titanium for carry: weight and corrosion properties |
| WGS-005 | Why brass belongs with titanium here | Material allocation: titanium for carry, brass for desk |
| WGS-006 | Why this set fits onboarding | Onboarding use mapping: access, setup, meetings, desk |
| WGS-006 | Why the access card holder leads the set | Access card holder: first-use timing and daily frequency |
| WGS-007 | Why the spinning top works in a desk set | Spinning top: desk category and tactile function |
| WGS-007 | Why brass and steel fit this combination | Material allocation: brass for hand interaction, steel for drink |

## 三、结构实施建议

**Definition 标签：**
每套新增的 Definition 字段，作为内容本身没有问题。但如果在页面上以 "DEFINITION" 作为可见标签展示，买家会感觉是 SEO 标注而非产品文案（与 WP-101 的 "QUICK ANSWER" 标签是同类问题）。建议去掉标签，内容融入页面正文或作为套件介绍段落展示，不单独标注。
