# Distributor Screening Funnel — Wischos Gift

A fast 3-tier filter for deciding whether a promotional products distributor or gifting agency is worth approaching as a Wischos Gift customer. Designed for SOHO-scale outbound (1 person doing prospect research).

## When to use this skill

Trigger when the user:
- Names a specific distributor / merchandising / gifting company and asks for an evaluation
- Asks "should I approach [company]?"
- Asks "is [company] a good fit?"
- Asks how to filter / qualify / screen LinkedIn search results for distributors
- Wants a fit score for a potential B2B reseller

Do NOT use for:
- End-corporate buyers (banks, law firms, HR procurement)
- Direct enterprise gifting requests
- Existing warm leads who already sent an inquiry

## Wischos Gift fit profile (the baseline)

The ideal Wischos distributor customer:

| Dimension | Target |
|---|---|
| Headcount | Up to 50 employees (smaller is fine — even single-operator SOHO works) |
| Annual revenue | USD 0.5-15M |
| Geography | AU, NZ, SG, UAE primary · HK, UK, CH, SA secondary |
| Imports directly | ✅ Has importer code, books LCL containers |
| Product positioning | Mid-to-premium curated programs (not commodity catalog) |
| Decision speed | Founder/Director-led, not RFP-driven |
| MOQ tolerance | Can commit to 50-500 sets per project |
| Client type | Corporate B2B (not consumer retail) |
| Founding year | No restriction — new agencies welcome if positioning fits |
| Multi-city offices (same country) | Not a concern — only multi-country/global scale is a flag |

## The Funnel (Tier 0 → 1 → 2 → 3)

Run prospects through this in order. Drop them at the first failure.

### Tier 0 — Hard-kill keyword scan (5 seconds, before any other check)

Before any LinkedIn or website review, scan the company's homepage / About / tagline for these **commodity-tier keywords**. If **any 2 hit, or any 1 hits prominently**, → **DROP immediately** (skip Tier 1-3).

**Auto-Drop keywords:**

| Keyword family | Examples |
|---|---|
| **Scale-catalog** | "10,000+ products" / "5,000+ SKUs" / "thousands of items" / "huge range" / "browse our catalog" |
| **Factory direct** | "factory direct" / "we deal direct with factories" / "factory advantage" / "direct from manufacturer" |
| **Price-beat** | "price beat guarantee" / "match or beat any quote" / "lowest price assured" / "cheapest" |
| **Rush turnaround** | "24-hour turnaround" / "next-day delivery" / "express service" / "rush orders welcome" |
| **Trade/wholesale-only** | "trade only" / "wholesale only" / "to the trade" / "no end-user sales" |
| **Own manufacturing** | "our factory" / "in-house production" / "own manufacturing facility" |
| **Distributor platform** | "PromoData" / "catalog feed" / "API for distributors" / "marketplace for promo distributors" |
| **Bulk/sea-freight** | "sea freight savings" / "bulk warehouse" / "stock available" + "container loads" |

**Why this matters:** these signals reliably identify companies that either (a) already self-source large catalogs (Dynamic Gift, Cubic Promote), (b) ARE the wholesaler not the buyer (TRENDS NZ, Brandengine), (c) compete on speed/price not curation (24h rush operators), or (d) self-manufacture (Matrix Promotion). Wischos cannot compete or partner with these.

Expected pass-through: ~60-70% survive Tier 0.

### Tier 1 — 5-second scan (LinkedIn search results / Google)

Check these before clicking into the company page:

**Pass criteria:**
- Headcount **up to 50 employees** (smaller is fine — even 1-5 person SOHO works if positioning fits)
- Location is in a target market city (Sydney, Melbourne, Brisbane, Auckland, Wellington, Singapore, Dubai, Abu Dhabi, Hong Kong, London, Zurich, Riyadh)
- Industry tag includes "Promotional Products" / "Marketing Services" / "Corporate Gifts" / "Branded Merchandise"
- Multi-city offices within the same country are **fine** — only multi-country/global operations are a flag

**Fail criteria (skip):**
- **>50 employees** (likely has internal sourcing — no room for Wischos)
- Industry tag is "Retail" / "Wholesale Distribution" / "Consumer Goods" / "Apparel"
- Outside target markets (US, India, generic global)
- Operating across 3+ countries (multinational scale — sources at a different level)

Expected pass-through: ~30%.

### Tier 2 — 30-second company page review

Open the company's LinkedIn page or website. Read the About / Tagline / recent posts.

**Green flags (each adds confidence):**

| Signal | Meaning |
|---|---|
| About says "imported direct" / "sourced overseas" / "China sourcing" / "we work with overseas factories" | Self-imports ✅ |
| Tagline / About uses "bespoke" / "curated" / "tailored programs" / "considered gifting" | Mid-to-premium positioning |
| **Explicit "Premium distributor" / "Premium gifting" tagline** | Same tier as Wischos — language match |
| **Wellness / mindfulness / self-care niche positioning** | Direct fit for The Pause set + adjacent metal pieces |
| **Indigenous / cultural niche** (Māori, Aboriginal, heritage-led storytelling) | High-differentiation positioning where Wischos's curated metal sets land cleanly |
| Photos are lifestyle / client case studies / factory visits | Not a catalog reseller |
| Customer logos or case studies feature corporate / executive / VIP clients | Matches Wischos use cases |
| Government supplier listing (e.g., buy.nsw.gov.au, SG GeBIZ) | Handles real procurement |
| Recent posts within last 30 days | Company is active |
| 500-5000 LinkedIn followers, monthly post cadence | Decision-makers are online |

**Red flags (each is a strong reason to drop):**

| Signal | Meaning |
|---|---|
| "Lowest prices" / "discounts" / "deals" / "bulk savings" prominent | Buys stock, not custom |
| Homepage dominated by catalog product thumbnails / "Browse our catalog" / "Add to cart" | Catalog reseller — wrong segment |
| Specialties tags are mostly Apparel / Print / Signage / Embroidery | Garment/print primary, not gift |
| "PPAI member" / "ASI distributor" badge + US-only operations | US market — not target |
| Photos are stacked cheap pens / T-shirts / mugs | Commodity-tier |
| Last post > 6 months ago | Possibly inactive |
| **Claims "10,000+" / "5,000+" SKUs or "thousands of products"** | Catalog reseller at scale — self-sources, no room for Wischos |
| **"Factory direct" / "direct from manufacturer" prominent** | Bypass-intermediary mentality — they ARE the buyer-side, you can't fit |
| **"Price beat guarantee" / "match or beat any quote"** | Commodity-tier — race-to-bottom segment |
| **"24-hour rush" / "next-day delivery" / "express turnaround" prominent** | Speed-driven commodity tier — doesn't match Wischos's curated lead-time model |
| **"Sea freight savings" / "bulk warehouse" / large stock holdings** | Bulk-only operator — wrong fulfillment model |
| **Self-manufacturing claim ("our factory" / "in-house production")** | They are a competitor, not a customer |
| **"Trade only" / "wholesale only" / "to the trade"** | They ARE the wholesaler — Wischos would be sub-tier supplier, near-impossible entry |
| **Printing/embroidery/engraving services are the homepage focus** | Decoration shop, not a gift sourcer — Wischos's metal sets aren't their core |
| **PromoData / catalog feed / "marketplace for distributors" / API platform** | They sell TO distributors, not buy product — wrong customer type |

Expected pass-through: ~50% of Tier 1 survivors.

### Tier 3 — 2-minute deep verification

For survivors of Tier 2, do a real check.

#### A. Website signals (30 seconds on homepage)

| What to check | Pass signal | Fail signal |
|---|---|---|
| Navigation | "Bespoke" / "Custom" / "Tailored" nav exists | Only "Shop" / "Products" / "Categories" |
| MOQ language | "MOQ from 100, custom programs" | "MOQ 25 from stock catalog" |
| Case studies / client logos | Lists Fortune 500 / mid-market corporates | No case studies, or only B2C brands |
| Material / sustainability story | Has a quality / sustainability narrative | No material discussion, only price |
| Order flow | "Request quote" / "Send brief" forms | Direct e-commerce checkout |

#### B. Decision-maker accessibility (1 minute on LinkedIn)

Go to Company Page → People tab. Look for:

| Role | Value |
|---|---|
| **Founder / Owner / Managing Director / CEO** | ⭐⭐⭐ Direct decision power, fast cycles |
| **Sourcing Manager / Procurement Manager / Director of Sourcing** | ⭐⭐⭐ Direct business overlap |
| **Sales Director / Head of Sales / Account Director** | ⭐⭐ Useful entry point, can refer |
| Only Designer / Marketing visible | ⭐ Decision-makers are hidden; harder to penetrate |

#### C. Composite Score (out of 10)

Add points only for confirmed signals from Tiers 2 and 3:

| Criterion | Points |
|---|---|
| Imports directly (confirmed in About / website) | **+3** |
| Mid-to-premium positioning | **+2** |
| **Explicit "Premium" tagline / positioning** | **+2** |
| Founder/Director visible and active on LinkedIn | **+2** |
| Corporate clients in case studies | **+1** |
| Accurate industry tag | **+1** |
| Active in last 30 days (post / news) | **+1** |
| **Niche fit (wellness / mindfulness / cultural / heritage)** | **+1** |

**Auto-Drop overrides (any one of these → instant Drop regardless of score):**
- Any Tier 0 keyword hit (10,000+ SKU / factory direct / price beat / 24h rush / trade only / own manufacturing / PromoData)
- Self-manufacturing claim confirmed
- Multinational scale (3+ country offices)

**Decision:**
- **Score ≥ 7** AND no auto-drop → Approach (LinkedIn connect, no sales note)
- **Score 5-6** AND no auto-drop → Park; revisit in 60 days
- **Score < 5** OR any auto-drop → Drop

Expected pass-through: ~40% of Tier 2 survivors.

## Argos-Type Customer Persona (priority-tier filter)

The **Argos-type** persona is Wischos's highest-value customer pattern, reverse-engineered from the Argos Promotional Products (NZ) interaction. For full details, see the companion reference document:

> `Argos-Type-Customer-Persona.md` (in this same folder)

After a prospect survives Tier 0-3 with a score ≥ 5, run them through the **Argos-Likeness Score** below to decide priority within the approach queue.

### One-line definition

> A **NZ / AU-based** (SG / UAE secondary), **owner-operated** promotional distributor with **5-30 employees**, **direct importer status**, **mid-to-premium mixed product mix** including occasional metal/curated programs, where the **Founder or Director personally responds** to outreach within 3-7 days.

### Argos-Likeness Score (0-10)

Award 1 point per TRUE statement (verifiable in under 5 minutes):

```
□ Owner / Director / MD visible on LinkedIn and posts personally
□ 5-30 employees on LinkedIn company page
□ Imports directly (stated in About or implied via supplier mentions)
□ Website features case studies or named client logos
□ Uses "bespoke" / "curated" / "considered" / "tailored" language
□ Posted within last 30 days (LinkedIn or website news)
□ Mixed product mix — drinkware + metal + gift sets (not single category)
□ Operates in single country (not multinational mega-distributor)
□ Client base includes B2B corporates, not consumer retail
□ No Tier 0 hard-kill keywords on homepage
```

**Priority decision:**
- **Score ≥ 7** → **First-priority approach queue** (use first-touch template below)
- **Score 5-6** → Standard approach queue (process via SKILL.md Tier 3 normally)
- **Score < 5** → Not Argos-type, but may still be a valid mid-tier prospect via standard flow

### Behavioral signals (the irreplaceable part)

These emerge only after first contact. **5+ of these 8 in the first 2 exchanges = confirmed Argos-type, treat as nurture priority even without immediate sale:**

- Founder / Director replies personally (not via assistant or sales rep)
- Willingly shares competitor pricing or local reference points
- Uses understated rejection ("a little high") rather than ghosting
- Specifies price isn't the only factor
- Leaves door open on rejection ("as/when available" language)
- Sends concrete enquiry (specific SKU + quantity + destination)
- Distinguishes metal vs non-metal product tiers
- Acknowledges supplier's effort in reply tone

### Anti-Argos signals (instant disqualification)

- Reply comes from sales rep / account exec, not Founder/Director
- Uses RFP / tender process
- Pure yes/no replies with no explanation
- Ghosts after initial enquiry
- Opens with "send us your best price"
- Auto-RFQ signature with "no follow-up please"
- LinkedIn company page hides Founder/Director identity

### First-touch template for Argos-type (proven structure)

Use this exact 4-line structure (~80 words):

```
1. Market acknowledgment (1 line)
   → "Saw [company] serves [their specific niche] in [market]."

2. Specific spec signal (1 line — key differentiator)
   → "We work mainly on metal sets — brass crown, anodised aluminium
       body, stainless steel accents — for executive and milestone briefs."

3. Soft offer with no push (1 line)
   → "Capability sheet attached if useful for future briefs."

4. Nurture door (1 line)
   → "No urgency — happy to be on file when a metal-leaning enquiry
       comes up at your end."

Sign off: "Best regards, John"
```

**Why this works for Argos-type:** No pricing claims, specific material vocabulary signals trade competence, "future briefs" framing matches their long-cycle thinking, no urgency respects owner-operator pace, ~80 words respects their inbox.

### Result-count tuning

LinkedIn surfaces strongest matches first, then degrades. Tune filters to land in the quality sweet spot:

| Result count | Action |
|---|---|
| < 30 | Too tight — remove one filter (try removing Service Category first) |
| 30-80 | ✅ **Sweet spot** — best signal-to-noise |
| 80-150 | Acceptable — focus only on first 30 |
| > 150 | Too loose — add one filter (tighten Industry) |
| > 500 | Re-do search with quoted keyword and stricter Title |

### Anti-patterns (don't)

- ❌ All 8 filters at maximum strictness → LinkedIn returns 0-3 results
- ❌ Search "gifts" or "marketing" without quotes → unusable noise
- ❌ Title = "CEO" → returns enterprise CEOs (wrong tier)
- ❌ Industry = Retail → B2C focus, wrong segment
- ❌ Adding all LinkedIn-suggested Current Companies → over-narrows to known companies
- ❌ Running the same combination every day → returns same people, fatigue
- ❌ Searching without quoted keyword → algorithm ignores intent

### Cadence (LinkedIn anti-spam thresholds)

```
- Maximum 5-8 connection requests per day
- Spread requests across 1-2 hours (not in a 60-second burst)
- Run 5 days, pause 2 days
- Vary search combinations across different days
- Personalize each connection note with name + country
- Never send > 3 identical connection notes in a row
```

LinkedIn's anti-spam algorithm will throttle accounts for:
- > 100 connection requests per week
- > 5 identical connection notes in sequence
- 10+ requests within 60 seconds
- Sustained reject rate > 70% (temporary lockout)

## Post-screen approach (for scores ≥ 7)

### Step 1 — LinkedIn connect (no pitch)

Send connection request to the highest-ranked decision-maker. Note is optional. If included, keep it to one line:

```
Hi [name] — connecting from a metal gift sourcing studio
in China. Happy to be a resource.
```

Never include sales language in the connection note. In AU/NZ/UK culture this gets flagged as spam.

### Step 2 — 2-3 days after acceptance, soft introduction

Send a LinkedIn DM (or email if contact public). Position Wischos as a **supplementary** sourcing option for metal-leaning briefs, not as a replacement for their existing suppliers. Reference one specific detail you saw on their website (shows you did research).

Template structure:
- One sentence acknowledging what they do
- One sentence positioning your fit ("where we'd be useful…")
- One sentence on a concrete capability (ChAFTA / NZ-China FTA / verified material specs)
- Capability sheet attached
- No urgency, no "let's hop on a call"

### Step 3 — Follow up in 6-8 weeks

Don't chase. Send a value-add update (new SKU launched, case study, industry insight). Long-tail relationship building.

## Special tactic: Lookalike mining from confirmed-fit accounts

When you have one confirmed-fit prospect (e.g., one who responded), use them as a seed:

1. Open their LinkedIn company page
2. Scroll to "Similar pages" or "People also viewed"
3. Check companies they follow / are followed by
4. Run those through the same 3-tier funnel

This typically yields 5-10 additional same-tier prospects per seed account, much faster than cold search.

## Common edge cases

### Q: Company has wide product range (apparel + drinkware + tech + bags), not metal-specialist

Treat as **B+ prospect**. Approach but with reduced expectations — you will be a **supplementary** supplier for their metal-leaning briefs only, not core. Lead with "complement, not replace" framing. Cap effort accordingly.

### Q: Company sells to government (NSW, SG GeBIZ, GCC tenders)

Treat as **green flag for legitimacy + procurement maturity**, but adds compliance overhead. Make sure all material claims are airtight before sending any quote. Avoid "solid brass" when you mean "brass-accent aluminium" etc.

### Q: Headcount shows only 2-3 employees on LinkedIn but website looks professional

Two possibilities:
1. **One-operator SOHO** with contractor team — surprisingly common, can still be a good fit if Founder is responsive
2. **Zombie account** — abandoned company

Check: when was the last LinkedIn post? Are there active job listings on their website? Is the domain renewed (whois)? If active signals present → treat as SOHO and approach.

### Q: Founder runs multiple companies (visible on their LinkedIn profile)

Slight yellow flag. They may be stretched thin. But also means they value efficiency — your "one contact, end-to-end" pitch lands well. Score normally; expect slower response times.

## Anti-pattern checklist

Don't:
- ❌ Mass-add 100+ companies in a day (LinkedIn flags and restricts)
- ❌ Send capability sheet in the connection note (looks desperate)
- ❌ Ask "interested in our products?" without context
- ❌ Approach the same company through multiple employees simultaneously
- ❌ Pitch lowest price (you can't win that — your edge is curation + materials)

Do:
- ✅ Personalize each first message with one specific website detail
- ✅ Pace connection requests at 10-20/day max
- ✅ Wait 2-3 days between connection acceptance and first DM
- ✅ Keep first message under 80 words
- ✅ Always offer to be "a resource" rather than "a vendor"

## Output format when applying this skill

When asked to evaluate a specific company, structure the response as:

1. **Company snapshot** (location, size, revenue, products, decision-maker contact)
2. **Tier 1/2/3 results** (which signals matched)
3. **Composite score (X/10)**
4. **Decision** (Approach / Park / Drop)
5. **Approach strategy** if score ≥ 7 (which decision-maker, what hook, what to avoid)
6. **Risks to flag**

Keep responses concise — the user is operating at SOHO scale and needs actionable verdicts, not exhaustive research.
