# 客户采购背景调查工作流

> 触发条件：给出一家公司名称，要求调查并判断是否为目标客户

---

## Step 1 — 查现有档案

先搜，不重复做工：

- `memory/` 目录 → 查 `project_[公司名].md`
- `临时/` 目录 → 查 `临时/澳大利亚/` 或 `临时/加拿大/` 等对应国家文件夹
- `MEMORY.md` 索引 → grep 公司名

找到已有档案 → 加载，跳到 Step 4 补缺口。  
没有 → 继续 Step 2。

---

## Step 2 — Firecrawl 全站爬取

用 `firecrawl` skill 完整爬取：

```
firecrawl scrape https://[domain]
```

重点页面：`/about` `/products` `/services` `/brands` `/clients` `/team`

同时查 APPA/PPPC/PPAI 成员页（如有）。

补充来源：
- ImportYeti / Volza（进口记录）
- LinkedIn 公司页（员工数趋势、职位招聘）
- ASIC（AU）/ NZBN（NZ）/ Companies House（UK）等注册信息

---

## Step 3 — 分析供应链位置

判断客户在供应链中的层级：

| 层级 | 信号 |
|---|---|
| **进口商**（最佳） | ImportYeti 有记录、"direct from factory"、中国办事处 |
| **一级分销商** | APPA/PPPC 会员、全国覆盖、完整目录 |
| **二级分销商** | 通过 AU/NZ 本地批发商（DEX/ProBrands/Trendz 等）采购 |
| **Decorator / 印刷商** | 只做品牌定制，不负责采购 → **直接跳过** |
| **品牌商** | 自有产品线 → 不同话术 |

---

## Step 4 — 梳理核心业务与产品线

- 主营方向（服装 / 科技 / 文具 / 礼品 / 饮品 等）
- 是否有 **Gift Sets 品类**？多少 SKU？价格区间？
- 金属产品存在感（笔、桌面配件、EDC、饮品器具）
- 服务的终端客户类型（企业 / 政府 / 零售 / SMB）
- Kitting / 组套能力？

---

## Step 5 — 目标客户判断

打分（各 0–100）：

**Fit 分** = 供应链位置 + 金属礼品空白程度 + 地理覆盖  
**Value 分** = 终端客户质量 + 目录投入规模 + 成长信号

| 等级 | 分数条件 | 行动 |
|---|---|---|
| **A** | 两项均 ≥ 75 | 优先外展，个性化 |
| **B+** | Fit ≥ 70，Value ≥ 60 | 主动外展，LinkedIn + 邮件 |
| **B** | Fit ≥ 65，Value ≥ 55 | 排入外展队列 |
| **B-** | Fit 60–64 | 群发邮件纳入 |
| **C+** | 一项偏弱 | 观察，群发可纳入 |
| **C** | 两项均弱 | 不主动外展 |
| **D** | 硬性排除 | 直接跳过 |

**D 级直接排除条件：**
- 自有中国采购办公室 / 工厂直采关系已成熟
- 纯 Decorator，无采购职能
- 品类完全错位（纯服装 / 安全防护等）
- 网站已停用 / 公司休眠

---

## Step 6 — 供应链痛点 + 切入角（仅 B- 及以上）

**常见痛点对照表：**

| 痛点 | 信号 | Wischos 切入角 |
|---|---|---|
| Gift Set 品类极薄 | <5 个 SKU | "现成可报价的金属套件，填补品类空白" |
| 无高端礼品层 | 无 $30+ FOB 产品 | "企业礼品升级，留存率更高" |
| 全是塑料，无金属 | 目录零金属 | "材质本身就是差异化" |
| 供应商交期慢 | 客户投诉 / 急单需求 | "标准 25–35 天，可建议缓冲方案" |
| MOQ 门槛过高 | 提到 MOQ 痛点 | "100 套起，可按项目情况沟通" |

输出 2–3 句：最可能的痛点 + 针对这家公司的具体切入角度。

---

## 输出格式

```markdown

日期：[today]  等级：[X]（Fit[n]/Value[n]）

**基本信息**
成立：/ 总部：/ 员工数：/ 股权结构：
行业协会：APPA / PPPC / 其他

**供应链位置**
[一级分销商 / 进口商 / 等] — [一句话证据]

**当前业务**
主营：[核心品类]
Gift Sets：[有 / 无 — SKU 数量，价格区间]
金属产品：[有 / 无]
主要终端客户：[行业或具名]

**采购信号**
- 进口来源：[ImportYeti 结果 或 未知]
- 目录规模估算：
- Kitting 能力：[有 / 无 / 未知]

**目标客户判断**
等级：[X] — [两句话说明理由]

**供应链痛点 + 切入角**
[2–3 句，具体到这家公司]

**关键联系人**
[姓名] — [职位] — [邮箱] — [LinkedIn]

**下一步行动**
[LinkedIn 邀请 / 个性化邮件 / 群发 / 观察 / 跳过]
```
