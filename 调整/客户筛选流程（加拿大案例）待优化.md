# 客户筛选流程（加拿大案例）待优化

**建立时间：** 2026-08-08
**适用市场：** 加拿大（PPPC名单）；可复用于 AU/NZ/UK/EU
**当前状态：** 待优化 — 基于加拿大1335家初筛 + 二次机会筛选经验总结

---

## 流程概览

```
原始行业名单（1000-2000家）
    ↓ 第一阶段：初筛
B/B-/C+/C/D 五级评级 + 建档
    ↓ 第二阶段：机会筛选
精准目标20-40家 + 优先级排序
    ↓ 第三阶段：外展准备（待补充）
联系人确认 + 开发信定制
```

---

## 第一阶段：初筛

### 数据来源
- 加拿大：PPPC官网会员名单（1335家）
- 澳大利亚：APPA官网会员名单
- 未来市场：BPMA（英国）/ Promota（爱尔兰）/ ASI（美国）等

### Gate 1 — 名称预筛（不搜索，直接 D）

名称含以下关键词 → 直接评 D，跳过搜索：

```
apparel / wear / embroidery / screen print / graphics / print /
buttons / sportswear / franchise / clothing / uniform / textile
```

附加直接 D 规则：
- 连锁加盟品牌（Fully Promoted / Proforma / Safeguard 等）
- 政府机构
- 供应商层/厂商（向分销商卖货的上游，非买家）

### Gate 2 — WebSearch 核查（每家1-2次搜索）

**评级标准：**

| 评级 | 标准 |
|------|------|
| **D** | 装饰商/制造商/错误行业/无记录Ghost/连锁加盟/政府机构/供应商层 |
| **C** | 小型泛化促销品，无套装/高端礼品证据，仅群发候选 |
| **C+** | 有隐性相关性（PPPC会员 或 incentive 或 writing tools 角度） |
| **B-** | 有 gift set / recognition / awards 类目 → 建简档 |
| **B** | 规模大 / 老牌15年+ / Fortune级客户 / 明确gift set+PPPC → 建详档 |

**特殊规则：**
- 重复记录 → 标注重复，写同评级，不重建档案
- CA海关数据不公开，ImportYeti记录少 ≠ 无进口，不以此降级

### 档案建立规范

**B 详档（必建）：**
```
基本信息表
主营业务
主要产品/代理品牌
与Wischos相关性（含gap分析）
联系建议
评级理由
```

**B- 简档（必建）：**
```
基本信息表
业务概况
相关性要点
切入建议一句话
```

**C/C+：** 不建档，仅 Excel 记录评级+结论

### 产出

- Excel：L列=评级（带颜色），M列=初筛结论
- 颜色：B=绿(70AD47) / B-=浅绿(A9D18E) / C+=黄(FFD966) / C=浅黄(FFE699) / D=红(FF7575)
- 档案：B/B- 存入 `Wischos Vault/市场端调查/[国家]/[公司名]/[公司-联系人].md`

## 第二阶段：机会筛选

**输入：** B + B- 档案（初筛后）
**目标：** 识别 Wischos 当前阶段真实可进入目标

### 正面信号（提升优先级）

| 信号 | 权重 |
|------|------|
| Owner / MD 单人决策 | ⭐⭐⭐ |
| 规模10-50人（决策快，无正式采购部门） | ⭐⭐⭐ |
| Gift set / recognition / awards 品类存在但薄 | ⭐⭐⭐ |
| 无中国办公室/驻厂直采团队 | ⭐⭐ |
| 有金属礼品但与 Wischos 产品有差异（可补充） | ⭐⭐ |
| PPPC 会员（有行业credibility，接受中国供货） | ⭐ |
| 老牌15年+（稳定，不是fly-by-night） | ⭐ |

### 负面信号（降权或排除）

| 信号 | 处理 |
|------|------|
| 有中国办公室 / 自有驻厂采购团队 | ❌ 排除 |
| 已被大集团收购（如 Staples / HALO 等） | ❌ 排除或降权 |
| 规模50人+且有正式采购部门 | ⚠️ 降权（无首单记录时不优先） |
| 产品与 Wischos 完全无交集 | ❌ 排除 |

### 产出

精准目标列表：
- 公司名 + 省份
- 原评级
- 机会判断（一句话）
- 优先级（高/中/低）
- 联系人 + 邮件（已知/未知）

## 第三阶段：外展准备（待补充）

> ⚠️ 本阶段尚未系统化，以下为初步框架

- 确认联系人邮件（unknown → LinkedIn / 官网 / Hunter.io）
- 按省份或买家类型分组定制开发信
- 外展节奏：LinkedIn 邀请 → 接受后私信 → 邮件 → 跟进

---

## 待优化项

1. **Gate 2 搜索效率** — 目前每家1-2次搜索，部分B-判断依据较薄
2. **C+ 处理方式** — 目前不建档，第三阶段难以利用
3. **第三阶段SOP** — 外展准备流程尚未标准化
4. **跨市场复用** — AU/NZ/UK 各有不同行业协会名单，Gate 1 关键词需调整
5. **A级定义** — 目前 A 级保留给"首单成交后"，需明确升A标准
