# 邮箱客户跟进

## 目标与边界

仅在用户明确提出分析范围后，读取其自己 Microsoft 365 邮箱中的相关邮件，并结合客户档案给出基于事实的下一步建议。

- 不因加载本文件而连接或扫描邮箱。
- 不保存完整邮件正文、附件内容或全量邮件副本；仅保存用户需要的本次报告摘要。
- 不发送、删除、移动、标记已读或改写任何现有邮件。
- 可生成回复**草稿**，但必须取得用户本次明确许可；草稿仍须用户在 Outlook 中审核和发送。
- 不将邮件正文传给第三方 AI、搜索或外部服务。

## 固定位置

- 邮箱自动化：`/mnt/d/Project/Wischos trading website/临时/mail_automation/`
- 邮箱分析命令：`scripts/analyze_mailbox.py`
- 客户档案根目录：`/mnt/d/Wischos Vault/Wischos gifts/市场端调查/`
- 本次报告默认目录：`临时/mail_automation/output/mailbox_reports/`

客户档案是权威的客户侧背景。优先读取与目标公司、联系人或邮箱直接匹配的 Markdown 档案；重点提取联系人、当前阶段、优先级、三个切入角度、风险、已有外展节奏和 CRM 备注。

## 接到请求后的流程

1. 确认请求范围：客户/联系人/公司域名或会话，以及时间范围。若用户未指定范围，先要求其指定，不能直接扫全邮箱。
2. 在 Vault 中查找匹配档案。按以下优先级匹配：已确认邮箱 → 公司域名 → 公司名与联系人名。免费邮箱域名（如 Gmail、Outlook）不可仅凭域名匹配；多个档案命中时必须列出歧义并请用户确认。
3. 通过邮箱自动化读取对应邮件。现有 `analyze_mailbox.py` 可做 Inbox / Sent Items 摘要分析；如果请求需要某封完整正文、完整会话或其他文件夹，先说明现有命令的范围，再以只读方式扩展自动化后执行。
4. 建立时间线：最后一次入站/出站邮件、是否已有回复、已承诺事项、报价/样品/附件/会议、明确时间点和未解决问题。事实与推断分开写。
5. 将邮件事实与 Vault 档案中的切入角度、风险、阶段和节奏交叉核对，给出下一步方案。
6. 输出报告和建议草稿。默认只展示给用户；只有用户明确要求时才调用 Outlook 回复草稿接口。

## 输出格式

按以下顺序输出，使用中文；给客户的邮件草稿用英文。

1. **匹配结果**：使用的客户档案路径、匹配依据和置信度。
2. **往来事实时间线**：日期、方向、主题、关键事实；不把推断伪装成客户已确认的事实。
3. **当前客户状态**：例如待首触达、已读未回、询盘待答、已报价待跟进、样品/附件待补、暂停或关闭。
4. **建议动作**：渠道、时机、唯一目标、使用的档案切入角度、风险/不宜做法。
5. **可审核文案**：如适用，提供一个英文主题和一封简洁草稿；不承诺价格、交期、样品或能力，除非邮件和档案中已有明确依据。
6. **需要用户确认的事项**：任何不确定的联系人、公司匹配、产品、价格、承诺或是否建草稿。

## 文案和跟进规则

- 读取 `调整/开发信写作原则.md`；若来自 LinkedIn 已建立联系，再读取 `调整/LinkedIn连接后跟进邮件写作原则.md`。
- 每封邮件只承担一个推进目标，保留一个低门槛 CTA。
- 对客户需求、预算、采购权或痛点缺少证据时，用条件式表达，不得臆测。
- 不把 Wischos 定位成替代客户现有供应链；成熟 distributor / gift agency 的定位是处理标准目录之外的计划型定制金属项目。
- 首次触达默认不附完整目录；除非已有往来邮件或客户档案明确表明已承诺发送。

## 安全闸门

执行前必须满足：

- 用户本次明确要求读取邮箱，且范围可识别。
- 仅访问 `/me/...` 下用户自己的邮箱；不访问共享邮箱或其他人的邮箱。
- 任何创建草稿、发送、移动、删除、标记、分类等写操作，都需要本次请求中的明确授权。
- 全量邮箱扫描只能在用户明确说“扫描全邮箱”时执行，并应先说明范围、预计报告内容和不会保存完整正文。

## 手动唤醒

此 Skill 是项目内 Markdown 文档，不是全局内置功能。每次使用时，在请求中明确写：

```text
请读取并严格按
/mnt/d/Project/Wischos trading website/调整/mailbox-customer-followup/SKILL.md
执行：分析 [客户/联系人/域名] 在 [时间范围] 的往来邮件，结合 Vault 档案给出下一步方案。不要发送或修改邮件。
```

示例：

```text
按邮箱客户跟进 Skill，分析 Promo Mojo 过去 30 天的邮件往来；结合 Vault 档案给出下一步和英文回复草稿，不要创建草稿或发送邮件。
```
