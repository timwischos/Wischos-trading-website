# Wischos 外贸开发信(Cold Email)写作原则

> 内化自毅冰的开发信内核(痛点→卖点→行动 / Mail Group / 价值前置 / 反自嗨 / solution provider 背书),并按 Wischos「定制金属礼品、无现货样品、trader/sourcing partner」的真实定位落地。
> 署名:John Lui · Wischos Gift · wischosgift.com

---

## 0. 先有调查,再写信(和 customer-analysis skill 联动)

开发信**不从零写**。写信前必须完成以下两步，缺一不可：

### Step 0a：先读现有客户 MD 档案（强制）

档案位置：`临时/` 目录下对应国家/公司文件夹。

读档案后，提取并列出以下字段供用户确认，再继续写信：

| 提取字段 | 用途 |
|---|---|
| 综合优先级 / Fit Score / Value Score | 决定投入开发资源的深度 |
| 供应链痛点（结构性风险 + 痛点诊断） | **Demand 痛点**（开头切入） |
| 中国供应商最佳切入角度（Angle 1/2/3）| **Advantage 卖点**（我能解什么）+ 产品配对 |
| 主要产品线 / 金属品类空白 / 产品四问 | beyond-catalogue 判断、例子选择 |
| 联系人优先级矩阵 / 决策力 | 发给谁、称呼、语气轻重 |
| 结构性风险 | 禁写项判断（不踩价格竞争、不碰已锁定品类） |

**如无现成档案**：必须先完成 customer-analysis，生成采购背景档案，再写信。不得跳过直接写信。

### Step 0b：喂档案内容进开发信框架

| 调查产出 | 喂进开发信的哪一环 |
|---|---|
| 供应链痛点 / 痛点诊断 | **Demand 痛点**（开头切入） |
| 中国供应商最佳切入角度 | **Advantage 卖点**（我能解什么） |
| 主要产品线 / 金属品类空白 / 产品四问 | 产品配对、beyond-catalogue 判断 |
| 联系人优先级矩阵 | 发给谁、称呼、决策力对应语气 |

没有调查就写信 = 群发自嗨,违背本原则。

补充:
- **优先发给具体负责人**(owner / director / procurement / category lead),其次才是 sales@ / info@ 这类泛邮箱。
- 如果是**朋友介绍 / 展会认识**拿到联系方式,开头可以交代来源;如果只是网站搜索到邮箱,不必硬写"how I got your contact"。

### Step 0c：调查必须核实的四个常见误判（强制）

写信前，以下四点必须用 firecrawl 官网验证，不能靠 LinkedIn 推断或档案旧结论：

| 误判类型 | 错误做法 | 正确核实方式 |
|---|---|---|
| **"有HK/海外直采"** | LinkedIn 写 "Global Sourcing" = 有直采能力 | firecrawl 官网 About/Services 页，找具体文字证据；无证据 = 不成立 |
| **"客户logo = 该品类需求"** | 官网展示 Codan logo = 他们向客户卖金属礼品 | logo 墙只证明合作关系，不证明品类；需找具体案例/产品页印证 |
| **平台定位** | 有 Pens 分类 = 有 premium 金属笔需求 | 抓产品页看**价格区间**：$0.53 起 = commodity 平台，切入 premium 无意义 |
| **营销语言** | "Event Management / Branding Solutions" = 高端定制能力 | 看实际产品目录和价位，不看 tagline |

**快速判断公式**：firecrawl 官网 → 看最便宜产品价格 → 低于 $2 起步 = commodity 平台 → premium 金属礼品切入角大概率无效。

## 1. 底层逻辑:痛点 → 卖点 → 行动(内化自毅冰)

每封信都服务这三步,缺一不可:

1. **Demand 找到痛点** —— 用调查里诊断出的**具体**痛点(目录同质化 / 利润挤压 / 金属品类空白 / 定制浅 / 无套件 / MOQ·交期),不泛泛说"想拓展供应商"。
2. **Advantage 秀出卖点** —— 只亮 Wischos 能解的**那一个**:工厂直供保利润 / 改形开模真定制 / 金属套件升一档 / beyond standard catalogue。**翻译成客户利益,不自嗨。**
3. **Call To Action 引导行动** —— 一个低门槛动作,让对方容易点头。

---

## 2. 价值前置 / WIIFM / 反自嗨(内化自毅冰)

- 永远写"**对方能得到什么**",不写"我们多牛"。
- **翻译思维**:把规格/产能/工厂 → 翻成客户利益。
  - ✗ 自嗨:"我们有阳江/东莞/中山工厂网络,25–35 天交期。"
  - ✓ 利益:"能赶在你活动档期前,把定制金属礼品交到位。"
  - ✗ 自嗨:"MOQ 仅 100 套。"
  - ✓ 利益:"小批量也能起订,适合 VIP / 特定项目,不用压一堆库存。"

---

## 3. 定位与背书(Wischos + 毅冰 solution provider)

- 定位句:`I help build custom metal gift options from China` —— solution / sourcing partner,**不是**低价 reseller,**不冒充**工厂。
- 材质 + 开放例子:`brass, stainless and titanium pieces like pens, EDC or desk gifts`。
- 成熟分销商 / 有固定供应商 → **beyond standard catalogue** 定位,不写"补品类空白"。
- 若客户官网已有 `Indent / CFO / Offshore Production / Custom Factory Orders` 等海外定制能力,不要写 `help you import from China` 或暗示替代其供应链。应写成 `support planned custom briefs alongside your existing catalogue / CFO channels`,定位为专项补位。
- 若客户已有相邻品类(例如已有 brass pens + pen gift sets),不要写"你们缺这个品类"。改写为**相邻升级**:更高感知版本 / 更定制化版本 / beyond standard catalogue 的项目补位。
- 用词谨慎:除非邮件主体确实是工厂,避免 `we manufacture`。优先用 `we develop` / `we build` / `we support` / `we help build custom metal gift options`。
- **背书(毅冰式,但只用真实的)**:若确有合作过的行业/客户类型,可点一句"做过 [行业/某类] 的定制金属礼品"传递实力——**绝不编造**,无真实案例就不写。

---

## 4. Mail Group:开发不是一封,是一组(内化自毅冰,Wischos 化)

核心:**第一封只是开始,用一组邮件多维展示专业,循序渐进。**

- **拉开时间发**(隔几天 / 1–2 周一封),不一天轰炸,避免"邮箱被炸"。
- **每封换主题、换价值维度**,且**每封都有新内容**,别重复、别像 spam。
- **一封只承担一个主主题**:不要把公司介绍、报价、认证、产品推荐、能力说明全塞进同一封。拆开以后,客户更容易理解、转发、存档。
- **Wischos 版分层序列**(替代毅冰的"测试报告/验厂报告",因为我们卖定制金属礼品):
  1. 切入价值:痛点 + 一个角度
  2. 相关材质/产品方向 + 2–3 个对口例子
  3. **mockup**:把客户 logo P 到产品上 / 某类 brief 的定制案例
  4. 季节·项目触发:年末礼品 / onboarding / VIP / closing gift
  5. 轻量能力点:工厂网络、MOQ 100、交期、定制范围(点到为止)
- 节奏对接 customer-analysis 的 Day 0/3/5/7/14/30/60/90。
- 可用**邮件阅读回执**判断是否打开(毅冰式):看了不回也没关系,知道看过、对口就持续跟进。多次触达建印象,客户常第 4–5 次才回。

---

## 5. 第一封结构：五步骨架

第一封按以下五步展开，每一步只完成一个任务：

1. **客户特点 + 对应痛点**：首句必须同时写出调研到的客户特点，以及该特点可能带来的具体业务难题。客户特点应尽量来自对方自己的定位、承诺、产品结构或公开原话。不能只写 “I noticed you sell...” 证明看过网站，也不能把“行业常见问题”冒充成该客户已经发生的痛点。无法证实客户确实遇到该问题时，必须用 `when... / if... / can be...` 写成条件式场景，不把推断写成事实。
2. **介绍自己 + 客户价值**：用 `I help build custom metal gift options from China` 说明定位，随后马上翻译成客户能得到的价值，例如承接标准目录之外的 brief、增加差异化选项、无需增加常备库存。
3. **举一个具体例子**：用一个产品、组合或 brief 把抽象能力具象化。例子必须与客户现有品类或使用场景相邻，避免一次罗列整条产品线。
4. **说明合作方式**：简洁交代双方如何合作，例如完整 metal-led set，或把单个金属件嵌入客户现有项目。不要在此堆 MOQ、价格、工厂和交期。
5. **留一个钩子**：只给一个低门槛 CTA，让对方容易回复，例如 `Worth me sending two or three examples relevant to your range?`

```
主题行
→ 客户特点 + 该特点对应的痛点
→ 我是谁 + 能给客户的价值
→ 一个具体且对口的例子
→ 两种以内的合作方式
→ 一个低门槛 CTA
→ 简短署名(John Lui · Wischos Gift)
```

**首句检查：**
- ✗ `I noticed you offer metal pens and drinkware.`（只有特点，没有痛点）
- ✓ `With your range already covering metal pens and drinkware, the harder briefs are often the ones that need a more distinctive finish or presentation than standard catalogue stock can offer.`（特点 + 情境化痛点）
- ✓ `Saw the Galaxy and Solar brass pens on your site, along with your custom Indent / CFO notes — so this may be relevant when a brief needs something with higher perceived value than standard catalogue pens.`（具体产品钩子 + 客户服务模型 + 条件式痛点）

**推断写法：**
- 对客户能力、客户 brief、采购痛点的判断,若未被证实,必须用 `may be relevant when...` / `could be useful when...` / `if a brief needs...`。
- 避免 `you are already handling...` / `you must need...` / `you should be looking for...` 这类替客户下结论的句子。

**已有 CFO / Indent 客户模板：**

```
Saw [specific product/category] on your site, along with your Indent / CFO notes — so this may be relevant when a brief needs [higher perceived value / more distinctive metal presentation] than standard catalogue stock.

We help develop [specific metal option] for planned corporate gifting programmes. One example is [one relevant set/item]. Worth me sending 2–3 examples in a similar direction?
```

全文 **≤120–150 词 / ≤5 短段**,手机一眼扫完。

## 6. 主题行

- 具体、像同行,不像广告。
- ✓ `Custom metal gift idea for [Company]'s VIP briefs` / `A metal option beyond your standard catalogue`
- ✗ `Best price` / `Manufacturer direct` / `China factory` / 全大写 / 感叹号 / 夸张承诺。

---

## 7. 关键分歧的 Wischos 取舍(毅冰"直给" vs 我们"软触达")

毅冰范文第一封就**附 offer sheet + 提免费样品**;Wischos 是**定制、无现货样品**,所以按我们的实际取**中间路线**:

| 维度 | 毅冰直给 | **Wischos 取舍(采用)** |
|---|---|---|
| 第一封附件 | 附 offer sheet | **不附完整目录、不报价**(定制无标准价,盲报无意义)。正文里可**点 2–3 个对口例子或一张 mockup** —— 这是 Wischos 版的"offer sheet":视觉化价值,而非价目表。 |
| 样品 | free sample on request | Wischos **无现货样品**。改成"can mock up your logo on a piece",或"有项目时再谈打样"。 |
| 价值 vs 关系 | 产品/报价前置 | **价值/痛点前置(学毅冰的直)**,但**不催单、不要需求、CTA 软(保留我们的软)**。 |

一句话:**痛点和价值要直,动作和姿态要软。**

第一封即使 MOQ / 交期是优势,也不急着写。先换取对方愿意看 2–3 个例子;MOQ、交期、打样放第二封或对方回复后。无现货样品时,不要写 `send samples`,改写为 `send 2–3 examples` / `mock up a direction`。

第二封以后再按兴趣**逐步释放材料**,而不是第一封全给完:
- capability sheet / distributor 版介绍
- 1 个对口 mockup 或 1 组同材质案例
- 轻量能力点(起订量、交期、定制范围、工厂网络)
- 只有在对方已表现出明确兴趣时,再谈更完整目录或具体打样

---

## 8. CTA(只给一个,低门槛)

- ✓ `Worth me sending 2–3 relevant examples?`
- ✓ `Want me to mock up your logo on one to show the idea?`
- ✓ `Worth me sending 2–3 more examples in a similar direction?`
- ✗ `Please send your requirements` / `Can I send our full catalogue?` / `What's your target price?` / `Do you have orders now?` / `Worth a quick chat?`(冷启动偏重) / 多个 CTA 并列。

---

## 9. 语气

平等、顾问式,不卑微推销。不过度夸赞、不用 hype 词(amazing / best / leading / world-class);诚实、具体;从中国主动说明(既筛选又坦诚)。

---

## 10. 禁忌清单

- 第一封**不发附件**(完整目录 / PDF / 价目表)
- 第一封**不写 MOQ / 价格 / 交期**(除非高度相关)
- **不冒充工厂**(Wischos 是 trader / sourcing partner,要透明)
- 无现货样品时,不写 `send samples`;可写 `send examples` / `mock up a direction`。
- 客户已有 CFO / Indent / offshore custom 能力时,不写"帮你进口"、"替代你现有供应商"、"教你做海外定制"。
- 不造紧迫感、不群发味、不一封信多个诉求、不一整屏长文
- **背书不编造**:没有真实案例就不提

---

## 11. 个性化底线

**至少一条针对对方的研究信息**(来自 customer-analysis)。没有 → 这封信不该发(等于群发)。

## 12. 推荐套件版结构（适用于有具体套件可配对时）

当客户档案已指向明确的使用场景，且有对口 WGS 套件时，用此变体替代第 5 节的五步骨架。

```
1. 钩子句
   用客户官网的具体原话或定位场景开头 → 点出这类 brief 的难点。
   条件式写法，不替客户下结论。

2. 自我定位（1句）
   "I'm with Wischos Gift in China. We help develop custom metal gift
   options for planned corporate gifting programmes..."

3. 套件推荐（视觉分行）
   "One example, one set that fits: [套件名]:"
   组件1,
   组件2,
   组件3（/组件4）,
   in a [包装描述].

4. 一句记忆点
   套件里最不寻常或最有话题性的单品，说明为什么它会被记住。
   无依据不写，不编。

5. 合作方式（可选，1句）
   完整套件 或 单件嵌入现有项目——二选一简述，不堆叠。

6. CTA（软）
   "Worth me sending 2–3 examples in a similar direction?"

7. 安全阀
   "If this isn't relevant, just reply 'no thanks' and I won't follow up."

8. 署名
   John Lui · Wischos Gift · wischosgift.com
```

**字数目标**: 130–160 词

### 套件选择约束（必须遵守）

套件推荐**不能主观配对**。推荐前必须核实以下至少一条：

| 依据类型 | 示例 |
|---|---|
| 客户官网已有该品类/相邻品类 | 已卖金属笔 → 推含笔的套件作升级 |
| 客户官网已有明确终端场景 | "vehicle handover" → 推 EDC/commute 套件 |
| 客户服务的终端行业有公认使用场景 | 企业 VIP 礼品 → 推 WGS-008 Quartet |
| 客户官网原话透露 brief 类型 | "beyond off-the-shelf" → 推定制感强的多件套 |

无法对应任何一条 → 不推具体套件，改用第 5 节五步骨架的"举一个例子"写法。

## 13. 发送前检查清单

- [ ] 是否先有该客户的「采购背景档案」?
- [ ] 主题行具体、不像广告?
- [ ] 第一句有针对对方的具体钩子(做过功课)?
- [ ] 痛点 → 卖点 → 行动 三要素齐全?
- [ ] 卖点是否翻译成了客户利益(没自嗨)?
- [ ] 定位是 solution provider、没冒充工厂?
- [ ] 如客户已有 CFO / Indent 能力,是否写成专项补位,而不是替代供应链?
- [ ] 如客户已有相邻品类,是否写成相邻升级,而不是"你们缺这个"?
- [ ] 只打了一个切入角度?
- [ ] 是否只举了一个具体例子,没有产品线倾倒?
- [ ] 只有一个低门槛 CTA?
- [ ] ≤160 词、没附完整目录 / 没报价 / 没过早写 MOQ 交期?
- [ ] 这是 Mail Group 的第一封,后面分层内容想好了?
- [ ] 若用推荐套件版：套件选择有客户侧依据，非主观配对?
