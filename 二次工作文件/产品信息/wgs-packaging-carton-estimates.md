# Wischos WGS Gift Set Packaging & Export Carton Estimates

生成日期：2026-06-10  
用途：根据网站当前套件组成、项目内规格文档、套件图片排布，以及已确认的 WGS-001 / WGS-002 口径，估算每套礼盒、EVA 内衬、出口外箱、装箱数和单箱毛重。  

## 估算口径

- 尺寸单位：mm，重量单位：g / kg。
- 礼盒尺寸为成品外尺寸估算，EVA 为内衬建议外尺寸。
- 毛重包含：产品净重 + 单套礼盒 + EVA 内衬 + 外箱 + 少量缓冲材料。
- EVA 密度建议：38-45 kg/m3，金属件之间要留独立槽位和取物半圆孔。
- 未在项目资料中明确写出宽度/厚度的单品，按图片和常见金属礼品结构做保守估算，并在表中标注“估算”。
- 正式报价前建议用实物样品复核：单品三维、礼盒纸板厚度、EVA 实重、外箱抗压。

## 统一外箱方案

如果为了采购纸箱方便，可以使用统一大外箱：**610 x 520 x 340mm**。

| 套件 | 统一箱建议装箱数 | 估算毛重 | 备注 |
|---|---:|---:|---|
| WGS-001-3 | 30套 | 18-20kg | 实际可装更多，但不建议超过 20kg |
| WGS-002-3 | 16套 | 16-18kg | 比原 12套方案更高，但箱内空隙需补强 |
| WGS-003-3 | 36套 | 17-20kg | 小件适合统一箱，但体积利用一般 |
| WGS-004-3 | 30套 | 18-20kg | 重量接近上限 |
| WGS-005-3 | 16套 | 15-18kg | 体积利用较好 |
| WGS-006-3 | 6套 | 13-15kg | 受笔筒厚度限制 |
| WGS-007-3 | 8套 | 14-16kg | 受杯子高度限制 |
| WGS-008-4 | 6套 | 14-16kg | 受杯子长度和整体宽度限制 |

统一箱适合海运或仓储简化；如果走快递/空运，不建议全部用统一大箱，因为 610 x 520 x 340mm 的体积重约为 21.6kg（按 /5000），小件套装可能被体积重反超。

## 需要实物复核的点

- WP-302、WP-303、WP-305、WP-307 的宽度/厚度需要样品实测。
- WP-106 本地供应商文档出现“56mm”与 WGS-008 文案“156mm”冲突；包装计算按 WGS-008 已上线口径 156mm 处理。
- WP-206 若最终选 14g 便携版，EVA 圆槽可缩小；当前按 30g / Ø40mm 标准版估算。
- WP-202 笔筒与 WP-407 / WP-408 杯类单品建议先打样确认是“卧放”还是“半嵌立放”，这会直接影响礼盒高度。
- 所有毛重为报价前估算值，正式 PI / carton mark 建议在首批样品和空盒实称后更新。
