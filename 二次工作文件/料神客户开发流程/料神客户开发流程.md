## 2 找到目标客户网站

### 你认为对口的客户，可能犯的错误
- 不是进口商（零售商、经销商、分销商），多数的 retailer、dealer、distributor 不进口
- 只是最终客户，从当地只买很少量的，或者只是下游的用户需要采购一下
- 你没有认真研究对方和积极查找联系方式，只是碰便发到客户的公共邮箱
- 找到的只是某个母公司的子品牌网站
- 在中国有工厂
- 主要进口的产品不是你这类产品

## 3（续）分析客户信息

### 了解问题（背景研究）
- 客人是不是专业做这一行的？（网站上去研究）
- 他之前采购过什么产品？有没有采购过此类品？（海关数据及初始追问）
- 是否在某些 B2B 网站发过询价？（GOOGLE 搜索看询盘）
- 这个客人的潜力有多大？（借助搜索引擎综合判断）
- 是不是美国市场的终端客户？（distributor 多不多，零售网上是否常出现的品牌）
- 这款产品一般在美国卖多少价格？（自己对行业的了解、敏感度）
- 平时同类客人的采购量大数多少？（自己对产品和行业的了解）
- 同行可能会做出什么样的价格？（竞争对手摸底）
- 什么样的包装适合目标市场？（对产品和行业的了解）
- 你给出的报价在国内同行里算哪种水平？
- 在美国 eBay 上看这个公司的产品 / 查是否在某品牌 Vendor List

### 分析：了解客户供应商数量
```
Google：alibaba.com + 客户公司名
BAIDU：广交会 + 客户公司名 / 广交会 + 客户公司名
GOOGLE：客户公司名 + contact（确定公司中国是否有办事处）
GOOGLE：客户公司名 -B2B

```

### 分析：了解客户供应商和产品
```
GOOGLE：alibaba.com + 类似供应商 + 出卖公司名
GOOGLE：glob-in-china.com + 类似应商类似公司名
```

### 客户角色分类

| 角色 | 特点 |
|------|------|
| 零售商（retailer） | 订单较小，了解销售价，销货急；关注价格、交期 |
| 经销商（dealer） | 关注利润、品牌、质量；地区优先 |
| 进口商/贸易商（importer/trader） | 产品线较完整，数量较大稳定，价格敏感；向生产企业采购，转售给零售商 |
| 批发商（wholesaler） | 主要注意中间利润通道；当地有物流仓储 |
| 分销商（distributor） | 分析行业深浅程度；当地物流完整；价格稳定利润中等 |

### 媒体分析
- 产品流通链：制造商（生产商）→（进口商）→（经销商）→ 零售商 → 消费者
- Google 看产品类型地位
- 上 SNS 找客户公司 CEO 名
- e-brand 找到被客户详细主要信息（成立时间，联系人信息）
- 发现产品品类周边产品客户公司的产品，并且有优势

### 利用供应商状况（是否在国内 B2B 平台）
```
GOOGLE：alibaba.com + 供应商公司名
made-in-china.com + 类似供应商公司名
globalsource.com + 类似供应商公司名
```
→ 用海关数据反向查找供应商出口记录，可发现其他客户

## 3（续）客户的供应 / 付款 / 交期

### 估量与报价
- 是否有旧询单在手先报（之前已确定报价在研究基础上）
- 合理选价立在研究完竞价的基础上
- 不过分让利，适当减小利
- 根据工厂报价参考进而报
- 付款日期设立

### 付款方式（优先级）
- **好**：款到打款 / 有些贷款公司对诚信产品高的工厂支持流量较好
- **理想**：发货前付款 → 首选做到最佳——结款 / 每单 / 每个月付
- **重要**：发货前付款到第一道最佳——结款 / 每单 / 每 1 天内付
- 核到证、取单、到电装备、报关期限、信用证付款方式
- 远期票据（比票据到期利达）
- 信用卡（大额外会费 6%）
- 延迟付款的合同：
  - 核定证、取单、到电装备、报关到外达到到信用证标准的结款
  - 双方都认知应得、协商分批分款
  - **NOT FUTURE NO ORDER**（此条要确认，不到条件不执行）
  - 如工厂货到后通则进收据证明
  - 工厂货汇时结

### 核对
- 客户提前 30 天到达工厂检验产品
- 打印发货单头：公司名 + 交货、电话、传真（**不给出工厂任何信息**）
- 用印制头找和客户连接关系点
- 避绕与工厂人直接渠道接触

### 交期延迟处理
- **不要把客户的问题变成自己的**（30%）→ 满足各个时间天数里给客户
- 原因梳理：
  - 原材料始终不足、生产停产
  - 材料导致停止生产
  - 生产计划距离超期量
  - 包裹邮件不及时
  - 交期延迟，少量并他无法响应生产，前进估储分量 → 一起生产率
- 根据客户供应商开门只让客交期延误方向：
  - 基于客户提供的日期时间，满足到别
  - 要求工厂供应的日期，并清楚说明
  - 向客户进解规定条件之前，解释自己的条件
  - 解释进款是一步方案性措施
- **工厂提前 20 天交货，可告知客户 10 天交货**
- 给小样小批货的有任务、更多 ok，点进面过，数量不太倾斜合作
- 延迟新客户下习惯的，注意开有成功率的成品

### 工厂 - 客户关系
- 好工厂关系才能开发更多客户
- 每个工厂可取出一到客户

## 7 产品

### 产品知识积累
- 产品的原材料、工艺、成本、性能、产量、规格及包装方式、价格、用途、最终使用场所和二次开发的可能性、产品机器原理
- 搜索渠道：百度搜索、百度百科、百度知道、Google、Google图片、维基百科(wikipedia)、各种行业论坛、工厂提供的资料
  - 借助查阅资料工具

### 原材料行情
- 有流动定期给新老客户发市场行情信息 → 阿里巴巴原材料市场频道

### 做成 EXCEL 惯性记录信息
- 原材料成本、加工的成本、机器的产量
- 工人工资/天、产量/天
- 打包工一天能做多少
- 根据工资再反推
- 另外还要包括水电、管理人工资、材料损耗率等

### 样品跟进
- 每次客送样品给客户收到约半个月后，给客户发一封样品的跟进的邮件，主要是询客户是否对产品有其他需求以及建议。

### 规格及包装方式（10 个问题）
1. 客户询问中的产品规格和包装方式，你是否按照不同国家不同行业用途记录过了？
2. 客户需要的样品的产品规格，你是否按照不同国家不同行业用途记录过了？
3. 已成交客户订单的产品规格和包装方式，你是否按照不同国家不同行业用途记录过了？
4. 目标国当地市场上的产品规格和包装方式，你是否找过该国几个主要的 B2C 零售网站上调查过？
5. 对一些行业内知名品牌的产品规格是否有基本了解？这些公司的网站是否研究过？
5. 一些对口的客户，无论已成交未成交，你是否有下载对方 E-catalog 下来然后分析的习惯？
6. 哪些规格客户报价时经常没有详细给出？
7. 哪些规格对成本有重大影响？
8. 哪些规格报价时可以有策略性地不报，报虚查？
9. 哪些规格是你可以做到且生产快，或者材料损耗少？
10. 哪些规格生产慢，产量低，或者材料损耗多？

## 8 询盘

### 真实性和有效性判断
1. 询盘是否和自己的产品有关？（毫无关系不着边际）
2. 询盘是否是同行在套价？（不少喜欢留个 SKYPE 伪装成客户）
3. 询盘是否是钓鱼邮件或者骗子？（新手最容易上钓鱼邮件的当）
4. 询盘是否值得回复？

### 有效询盘分类
1. **明确型询盘**：询盘中对产品的具体的规格，包装，数量都有明确描述。
2. **不明确型询盘**：询盘中对产品的具体的规格，包装，数量不太明确，但是这类询盘不代表没有好客户。

### 了解合作意向
- 之前是否有进口过这个产品（由此判断客户是否在国内有其他供应商，客户有可能之前是从当地进口商买货）
- FOB or CIF？按照哪个港口报价？（判断客户的供应商靠近什么地区）
- 客户的客户群体，是批发商、分销商 OR 零售商。（判断客户的价格接受能力）

## 9 报价

### 总体分析（报价前必做）
- 客人是不是专业做这一行的？（网站上去研究）
- 他之前采购过什么产品？以往有没有采购过此类品？（海关数据及初始追问）
- 是否在某些 B2B 网站发过询价？（GOOGLE 搜索看询盘）
- 这个客人的潜力有多大？（借助搜索引擎综合评价）
- 是不是美国市场的终端客户？（distributor 多不多，零售网上是否常出现的品牌）
- 这款产品一般在美国卖多少价格？（自己对行业的了解，敏感度）
- 平时同类客人的采购量大数多少？（自己对产品和行业的了解）
- 同行可能会做出什么样的价格？（竞争对手摸底）
- 有哪些可能影响报价的细节问题需要注意？什么样的包装适合美国市场？
- 你给出的报价在国内同行里算哪种水平？
- 开价高于实际想要的价格；客户是中间商，产品细的比较多，最不是特别大，供应商不多。
- 报满了的回复：`price can be negotiated according to different quantity.`
- **先分析客户是否真实，再分析大小及专注否**

### 如何报价
- 根据提出的问题的回复，按照需要，筛选产品，按长短期，报有优势的产品组
- **没必要做 pricelist**

### 可部分询问（Send me pricelist?）
1. `FOB or CIF？Which port you usually buy from?`
2. `For this industry, what's the main products you are buying?`
3. `For this product, what's the main specification you are buying? What's the packing way?`

### 后续动作
- 准备发现这类美产品业界客户
- 告知客户你的市场上有哪些产品与此类似比较，以及什么规格和款式的产品稳销，提供一些专业性的意见。
- 提供给客户在这个市场上销售成功的客户网站，请客户先去研究，然后确定对哪些产品有兴趣，之后给出详细报价。

### 报虚最叫小，关注细节
- 关注利情，产品不专业，具体细节不关注了解

### 案例示例
- 历史追踪信息：2011年注意的波士顿，考虑行业为食品包装，对有具体数量，不大。
- `We started the activity of general trading by providing daily food packaging products.` 网站上发现 PE glove 产品
  1. 首先访问客户，发现客户公司的介绍 about us 里面写着看
  2. 研究客户的网站，发现客户公司的介绍 about us 里面写看
  3. Google：公司名 没有发现多分信息
     - Google：网址
     - Google：公司名 + site:.pl
     - Google：网址 + site:.pl
  4. Map.google.com
  5. 研究域名的 whois 信息
- 例子询盘：`Good Morning, please provide FOB pricing of disposable PE gloves for 50 ctns (food grade). Thanks you, XXX`
