# LinkedIn & Cold Email Outreach Playbook

**目标流程**
```
LinkedIn好友申请（300字符，带hook）
  → 对方通过
  → 确认邮箱（见邮箱查找流程）
  → 调查背景（见调查清单）
  → 冷邮件 Email 1（发现需求，CTA = 聊聊）
  → Day 7：Email 2 跟进
  → Day 14：Email 3 + mockup 图（杀手锏）
  → Day 21：收尾
```

**邮箱查找流程（LinkedIn 通过后执行）：**

1. WebFetch 官网 Contact / About / Footer → 提取邮箱
2. 无个人邮箱时 WebSearch：`"联系人姓名" "公司域名" email` / `site:公司域名 "@"`
3. 有任意员工邮箱 → 推断决策人格式（`firstname@` / `first.last@`）
4. 完全找不到 → LinkedIn 私信直接要：
   > "Happy to send over a few specs — easiest by email. What's the best address?"

## 一、LinkedIn 好友申请（300字符）

### 分销商版
```
Saw [Company] works with [corporate gifting / promotional products] — 
we supply custom metal gift sets (brass, titanium, stainless) to 
gifting agencies adding a higher-margin, spec-driven category. 
Happy to connect if it's ever relevant.
```

### 企业终端版
```
Noticed [Company] has been [growing the team / expanding offices] — 
we work with HR and procurement on custom metal gift sets for 
onboarding kits and milestone recognition. Happy to connect 
if it's ever useful.
```

`[括号]` 部分根据调查替换。

## 二、冷邮件模板

### 分销商版

**Subject（选一）**
- `Metal gift sets — a gap in your current offer?`
- `[First name] — one question about your catalog`

**Email 1**
```
Hi [First name],

[HOOK — 1-2句，来自调查：近期动态、产品方向、市场布局、客户群变化]

We supply custom metal gift sets to gifting agencies and distributors 
— brass, titanium, stainless steel, laser-engraved, white-label 
packaging. Most partners use us for briefs where the client wants 
something more considered than standard promo items.

Curious whether that's a gap you run into — or if it's already 
covered in your current supplier mix.

Happy to share a couple of examples if worth a look.

[Name]
Wischos Gift | wischosgift.com
```

**Email 2（Day 7，无回复）**
```
Hi [First name],

Just following up on my note last week — happy to share some set 
specs and pricing direction if useful context.

No pressure either way.

[Name]
```

**Email 3（Day 14，mockup 图）**
```
Hi [First name],

Put together a quick visual — [客户公司 logo] on a couple of 
sets that fit your [awards / corporate gifting / promo] line.

[附：Photoshop/Canva mockup 图，客户 logo P 到 2–3 款 Wischos 产品]

Happy to send specs if any of these are worth a conversation.

[Name]
Wischos Gift | wischosgift.com
```

**Email 4（Day 21，收尾）**
```

I'll leave it here — if metal sets ever come up in a brief, 
feel free to reach out.

wischosgift.com/gift-sets has the current catalog.

[Name]
```

## 三、调查清单（写邮件前看什么）

| 来源 | 看什么 |
|------|--------|
| LinkedIn个人页 | 近期发帖、点赞、分享；职位变动 |
| LinkedIn公司页 | 招聘动态、文化内容、近期公告 |
| 公司官网 | 团队规模、行业、文化描述 |
| 新闻/PR | 融资、扩张、获奖、重大活动 |
| 产品/市场方向 | 他们服务的客户群、价格带、主推品类 |
