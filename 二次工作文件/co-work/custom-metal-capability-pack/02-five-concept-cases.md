# Five Use-Case Add-ons for WGS Metal Gift Sets

These are not a replacement for WGS-001~008. Use them as scenario labels and optional extensions when a distributor asks how Wischos fits a real client brief.

Start from productized set directions wherever possible. Only move into one-off custom development when the brief, budget and quantity justify it.

## 1. Productized Executive Metal Set

**Use case:** VIP client gift, executive gift, onboarding, professional services gift.

| Field | Reference |
|---|---|
| Product idea | A ready-to-quote metal set direction: pen + card holder / pen + desk piece / drinkware + metal accessory |
| Materials | Brass / stainless steel / aluminium / titanium depending on component |
| Processes | Laser engraving, brushing, polishing, PVD / plating where applicable, gift-box insert |
| MOQ | Around 100 sets, project-dependent |
| Reference FOB | Premium set range; quote from WGS-style configuration |
| Sample lead time | 7-15 days depending on sample availability and decoration |
| Production lead time | 25-35 days after approval |
| Customizable | Component mix, logo, finish, box insert, card, packaging |
| Risk notes | Keep configuration tight; do not over-customize before budget is confirmed |

**Best for:** Argos-type prospects asking for existing metal gift set options with branding.

| Field | Reference |
|---|---|

| Processes | CNC, stamping, die casting, laser engraving, plating, packaging assembly |
| MOQ | Around 100 pcs / sets depending on item |
| Reference FOB | Project-dependent |
| Sample lead time | 10-15 days |
