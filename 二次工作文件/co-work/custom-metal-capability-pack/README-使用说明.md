# WGS Productized Sets + Custom Metal Support Pack 使用说明

这套材料是 **现有 WGS-001~008 产品化套件和现有 distributor/corporate capability sheet 的补充包**，不是战略 pivot，也不是让你停止 outbound 重新开发产品。

核心判断：

> 继续主推 productized metal gift sets；只把 custom metal hero pieces 作为客户 brief 出现时的延伸能力。

适合发给 Inck Merchandise、The Promo Lab、BrandHK 这类已经懂 promo / sourcing 的客户。

## 文件清单

| 文件 | 用途 | 是否可直接给客户 |
|---|---|---|
| `01-client-facing-capability-sheet.md` | 一页式英文补充说明：WGS 套件 + off-catalogue metal support | Yes |
| `02-five-concept-cases.md` | 5 个可执行 use-case add-ons，不替代 WGS-001~008 | Yes，可选择性节选 |
| `03-custom-metal-project-brief-form.md` | 客户 brief 表 | Yes |
| `04-quotation-template.md` | 报价模板 | 内部为主，也可整理后发客户 |
| `05-qc-checklist.md` | QC checklist | 可作为信任材料节选 |
| `06-factory-vetting-checklist.md` | 工厂筛选表 | 内部使用 |

## 先后顺序

1. **主材料仍然是现有 distributor/corporate capability sheet + catalogue / WGS-001~008。**
2. 本文件夹只用于补充说明：当客户觉得普通目录不够、或者询问定制能力时，Wischos 能如何支持。
3. 不建议为这套材料暂停 outbound；能力是边卖边补。

## 对客户的推荐发送顺序

### 第一次轻触达

只发一句定位，不发附件：

> We supply productized metal gift set options, and can also support custom metal components when a brief needs something beyond standard catalogue items.

### 对方有兴趣后

发送：

1. 现有 WGS catalogue / distributor capability sheet
2. `01-client-facing-capability-sheet.md`
3. `02-five-concept-cases.md` 中最匹配的 1-2 个 use case
3. 询问是否愿意用 `03-custom-metal-project-brief-form.md` 给一个真实 brief

### 不建议首轮发送

- 过量 catalogue / 过量 SKU
- 大量 SKU
- 详细报价表
- 工厂清单
- 过度承诺“什么都能定制”
- 让客户误以为 Wischos 只做 one-off custom development

## 对 Inck / Adrian 这类懂中国供应链客户的注意事项

不要说：

- We can help you source from China.
- We are cheaper.
- We can make gift sets.（太泛）
- We have many factories.
- We can develop anything from scratch.（风险太高）

应该说：

- We have productized metal gift set directions ready to quote.
- We are not replacing your daily catalogue supply chain.
- The fit is planned premium metal projects beyond standard catalogue items.
- We can help when the brief needs a durable, premium, brand-specific metal piece.

## 不能做的事

- 不要 pivot 到纯 custom hero piece 模式。
- 不要暂停 38 家 prospect outbound。
- 不要重新开发 5 个全新产品线。
- 不要把这套材料当作替代 WGS-001~008 的新战略。
