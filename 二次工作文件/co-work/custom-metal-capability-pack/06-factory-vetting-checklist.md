# Factory Vetting Checklist for Custom Metal Projects

Use this before relying on a factory for client-facing concept cases.

## Factory Type

| Factory type | Best for | Needed? |
|---|---|---|
| CNC metal small parts factory | Titanium, stainless, aluminium, brass EDC and desk pieces | |
| Zinc alloy die-casting factory | Badges, tokens, openers, medals, custom shapes | |
| Metal pen / stationery factory | Metal pens, card holders, desk stationery | |
| Surface treatment partner | PVD, plating, anodizing, brushing, antique finish | |
| Packaging / assembly factory | Rigid boxes, EVA inserts, kit-ready packaging | |

## 10 Questions To Ask

| Question | Answer |
|---|---|
| What materials do you handle in-house? | |
| What processes are in-house vs outsourced? | |
| What is your realistic MOQ for custom projects? | |
| What is the sample fee and sample lead time? | |
| What is the production lead time at 100 / 300 / 500 pcs? | |
| Have you made similar items before? Ask for photos. | |
| Can you provide material statements or test reports if needed? | |
| What surface finishes are stable for this material? | |
| How do you inspect plating, logo and edge finishing? | |
| Are you willing to support small-batch serious projects, not only mass orders? | |

## Red Flags

- Says “everything can be done” without asking drawings/specs.
- Refuses to explain what is outsourced.
- No similar sample photos.
- Gives a low price before understanding material, finish, weight and packaging.
- Avoids sample approval or does not support pre-production sample.
- Cannot explain plating/finish risks.
- Does not want to handle 100-300 pc serious custom projects.
- Changes quote repeatedly without clear reason.
