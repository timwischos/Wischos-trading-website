# Custom Metal Product QC Checklist

Use for sample review and final production inspection.

## A. Sample Approval Checklist

| Check | Pass / Fail | Notes |
|---|---|---|
| Material matches approved spec | |
| Size matches drawing | |
| Weight feels acceptable | |
| Edges are smooth, no sharp burrs | |
| Surface finish matches approved sample | |
| Logo position is correct | |
| Logo method is clean and durable | |
| Colour / plating is acceptable | |
| Function works if applicable | |
| Packaging matches approved direction | |
| Client artwork and text checked | |
| Photos / videos recorded | |

## B. Appearance Inspection

| Defect | Acceptance note |
|---|---|
| Scratches | No visible scratches on primary face under normal light |
| Dents / pits | No obvious dents, pits or casting marks on visible surfaces |
| Burrs | No sharp burrs on edges, holes or functional parts |
| Colour difference | Must match approved sample within agreed tolerance |
| Plating unevenness | No visible uneven plating, peeling or staining |
| Logo defects | No missing strokes, wrong position, blur, overflow or colour bleed |
| Assembly marks | No glue overflow, loose parts or misalignment |

## C. Dimension and Weight

| Item | Standard |
|---|---|
| Length / width / thickness | Compare with drawing and agreed tolerance |
| Hole position / accessory fit | Must match approved sample |
| Weight | Compare with approved sample; record tolerance |
| Packaging size | Confirm before carton planning |

## D. Functional Checks

Use only where relevant.

| Product | Check |
|---|---|
| Pen | Writes smoothly; refill fits; clip secure |
| Bottle opener | Opens bottle safely; no deformation |
| Phone stand | Stable angle; does not slip |
| Keyring / EDC | Ring, screw or clip is secure |
| Magnet item | Magnet strength acceptable; no loose magnet |
| Desk object | Stable on flat surface; no wobble |
| Box | Opens/closes cleanly; insert holds product |

## E. Surface Treatment Checks

| Test | When to use |
|---|---|
| Tape test | Basic plating / print adhesion check |
| Dry rub test | Logo and surface durability |
| Alcohol wipe test | Only if finish allows; check before applying |
| Salt spray test | When customer requires corrosion resistance |
| Colour card comparison | For plated / anodized / painted finishes |
