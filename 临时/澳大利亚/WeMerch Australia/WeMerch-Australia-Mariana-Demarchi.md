## 采购背景档案

### 核心业务方向

WeMerch 是澳大利亚 Sunshine Coast 的 boutique branded merchandise / custom promotional merchandise studio，核心业务是帮助品牌设计和交付更有使用价值、更有记忆点的定制品牌周边。它不是传统低价目录型促销品分销商，而是项目制、设计驱动、强调 quality / sourcing / commercial outcomes 的小型 merchandise agency。

### 主要产品线

| 产品线 | 采购特征 | Wischos 相关性 |
|---|---|---|
| Corporate gift sets / client gift kits | 项目型、组合式、强调包装和体验 | 高 |
| Pens / writing items | 常规 merch，可升级为金属笔礼盒 | 高 |
| Keyrings | 地产礼盒、活动礼品常用 | 高 |
| Drinkware / travel mugs / aluminium bottles | 官网和 LinkedIn 均有证据 | 中高 |
| Presentation boxes / gift packaging | 礼盒化项目需要 | 高 |
| Event kits / swag bags | 多品类组合，通常价格敏感 | 中 |
| Retail-ready accessory collections | 可做小批量品牌配件 | 中高 |
| Uniforms / apparel / signage | 本地供应链或装饰商更适合 | 低，不主切 |

### 潜在采购需求

- 地产客户礼盒 / settlement gift：metal pen, keyring, custom house-shaped metal piece, stainless drinkware, gift box.
- 企业 onboarding / welcome kits：metal pen, lapel pin, desk accessory, stainless tumbler, presentation box.
- 客户答谢 / recognition gifts：premium pen set, metal card holder, bookmark, medal, commemorative coin.
- 活动和品牌 campaign：metal pins, medals, keyrings, custom-shaped metal pieces, EDC gifts.
- Retail-ready accessory range：metal keyrings, bottle openers, EDC tools, metal tags, small branded accessories.

### 供应链可能痛点

1. 本地目录产品同质化，难以支撑其 intentional / useful / memorable merchandise 定位。
2. 小团队需要低沟通成本、清晰规格、交期明确的项目型供应商。
3. 本地供应链适合现货加 logo，不一定适合 custom-shaped metal piece、特殊表面处理、金属礼盒和定制包装。
4. 客户需要更高感知价值时，普通塑料/纸品/软品不足以表达 premium 和 lasting value。
5. MOQ、交期和样品可能有阻力，需要明确只适合 planned projects，并用过往案例图、材质图板和 pre-production sample 管理预期。

### 中国供应商最佳切入角度

不要说：

> We can supply all promotional products.

应该说：

> We support planned custom metal gift projects beyond standard catalogue items.

中文理解：Wischos 不是替代 WeMerch 的澳洲本地目录供应商，而是在客户需要更有设计感、更耐用、更像礼品的金属定制项目时，作为中国端项目型供应补充。
