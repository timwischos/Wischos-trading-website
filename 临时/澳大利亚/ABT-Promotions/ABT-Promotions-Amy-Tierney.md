## 三个切入角度（优先级排序）

### Angle 1（最强）: The Executive Brief Gap — 填补高端金属礼品套件空白

- **为何成立**: 小型promo分销商常收到超出标准目录范围的executive gifting brief（3–4件金属套件、精装礼盒、logo刻字），只能外包给泛用代理，质量和利润均不稳定。Wischos提供专精金属礼品套件的工厂直供。
- **产品配对**: WGS-005 Executive Set / WGS-008 The Quartet
- **Hook sentence**: *"When a client asks for a premium metal gift set — pen, cardholder, flask, gift-boxed — do you have a reliable source, or does that brief usually go somewhere else?"*
- **风险**: ABT若90%业务是笔+挂绳+T恤，executive gift set brief可能不常见；需首封邮件验证

### Angle 2（稳健）: EOFY & Christmas Seasonal Lock-in

- **为何成立**: 澳洲EOFY（6月）+ 圣诞预订（10–11月）是两大采购窗口。分销商需提前锁定供应商以保证25–35天交期。5月接触正处最佳时机。
- **产品配对**: WGS-001 / WGS-006 The Onboarding Set
- **Hook sentence**: *"QLD distributors usually lock in their Christmas gift set suppliers by July — happy to get you our catalogue now so you have a source ready before the brief arrives."*
- **风险**: 若Amy今年已锁定供应商，季节性紧迫感低

### Angle 3（长期）: QLD Mining Sector Onboarding Kit

- **为何成立**: QLD是澳洲资源/矿业主导州，资源公司有强烈高端礼品文化（milestone awards、新员工入职套件、contractor recognition）。金属笔+名片夹+保温杯套件在此场景有高感知价值。
