## TRENDS / Tuapeka 覆盖与空缺

Tuapeka Gold Print / TRENDS 覆盖很强：

- 产品：pens、drinkware、stationery、gifts、key rings、badges、confectionery、business items、personal items、bags、hats、umbrellas、apparel、packaging 等。
- 装饰：pad print、flat bed screen print、rotational screen print、laser engraving、digital media print、dye sublimation、heat transfer、direct digital print、resin doming、injection/blow moulding。
- 规模：TRENDS 官方资料显示其为澳新 promotional industry 主要供应商，有 600+ staff；Marketwrite 页面写 TGP 每年印刷超过 1000 万支 promotional pens。

Wischos 可补的空缺：

| 机会点 | TRENDS 可能不够的地方 | Wischos 切入方式 |
|---|---|---|
| 标准目录外金属定制件 | 目录供应商强在现货 SKU 和装饰，不一定适合复杂非标金属件开发 | 定制形状金属纪念件、徽章、奖牌、压铸/CNC/电镀小五金 |
| 高端金属礼盒组合 | TRENDS 有 gift set，但多为现货组合 | 金属笔 + 桌面件 + drinkware + 定制包装的一体化礼盒 |
| 特殊材质和表面 | 装饰工艺强，但产品结构和材质仍受目录限制 | brass、stainless steel、titanium、PVD、拉丝、蚀刻、阳极氧化 |
| 项目型中国源头开发 | 本地目录交付快但成本结构高、差异化有限 | MOQ 100、25-35 天、FOB USD 18-50 的 planned custom project |
| Premium appreciation / recognition gifts | 普通促销品已覆盖 | 企业感谢礼、客户纪念礼、活动 VIP / speaker gift、recognition gift set |
