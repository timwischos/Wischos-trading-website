## 公司概况

ADZImpact Promotional Products 是澳大利亚 Queensland 的小型 promo / branded merchandise 服务商。其业务更像：

```text
Manufacturer / overseas supplier / local wholesaler
  -> Australian promo catalog supplier / importer
  -> ADZImpact Promotional Products
  -> Australian corporate / event / client-store customers
  -> End recipients
```

如果与 Wischos 合作，路径更像：

```text
Wischos
  -> ADZImpact
  -> ADZImpact 的企业客户项目 / client store / campaign
  -> Recipients
```

ADZImpact 的价值不是大批量进口，而是小型企业客户项目、专属商城、企业活动和品牌礼品方案中的金属高感知价值补充。
