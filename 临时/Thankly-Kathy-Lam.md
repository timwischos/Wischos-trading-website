## 与 Wischos 的契合分析

### Thankly 能否接受金属礼品？

**结论：结构性障碍，常规路径走不通。**

| 障碍 | 说明 |
|------|------|
| **邮寄模型** | Thankly 核心是轻量包裹全国邮寄，flat-fee 运费。金属套件重量（500g–1kg+）直接破坏运费经济学 |
| **自主选品** | Thankly 自行策划和备货产品，Wischos 需成为其平台供货商，门槛高 |
| **本地采购偏好** | Key differentiator 之一是"locally-made by Australian artists"，中国制造金属件与此冲突 |
| **场景错位** | Thankly 主打日常高频感谢，Wischos 适合低频高价值里程碑场景 |

**唯一可行路径**：企业客户指定大型 bespoke campaign，Thankly 作为协调方采购 Wischos 金属件作为特供组件。但这是边缘场景，不是 Thankly 常规业务。

### 优势（保留价值）
- **客户质量极高**：PwC / JPMorgan 级别——如果直接转介这些企业客户给 Wischos，价值巨大
- **澳洲市场**：Wischos 优先市场，无关税
- **成长窗口期**：新任唯一 owner，开放合作探讨

### 风险
- **产品不适配**：Thankly 平台本身无法承载金属套件
- **不是采购商**：她更可能是转介人，而非直接买家

## 开发策略

**优先级：三线，降级处理**——产品形态与 Thankly 平台结构性不匹配，直接销售路径走不通。

**真正价值**：作为**转介渠道**，而非采购客户。如果关系建立后，Kathy 愿意把有大型金属礼品需求的企业客户（JPMorgan、PwC 级别）转介给 Wischos，才是实质价值所在。

**联系优先级**：暂缓，待 J&F / Luxxe 等直接采购客户跑通后再考虑。

**若决定接触**，话术应聚焦转介而非销售：
> "你有 Salesforce / PwC 这类客户——他们有没有里程碑场景需要重型定制金属礼品（100 sets+）？那不适合走你们的邮寄流程，但我可以直接服务他们，你作为引荐方。"
