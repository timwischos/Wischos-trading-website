## 业务匹配分析

### 匹配模式

Wischos 产品 = Pro Image 在普通 promo catalog 之外可用于提升 perceived value 的 premium custom metal gifts。

Pro Image 能力 = 企业客户关系、促销品项目整合、conference / event packages、corporate gift / award 项目执行。

合作模式 = planned project backup supplier / premium metal upgrade，不替代其北美常规目录供应商。

### 最适合的合作方式

1. **Executive gifts / corporate gift sets**
   - 对应 Pro Image 的 corporate gifts、executive gifts、gift sets。
   - Wischos 可提供 brass/titanium pens、desk pieces、compact metal gift sets。

2. **Conference / event package insert**
   - 对应 conference packages、trade show giveaways。
   - 仅适合提前规划的活动礼品，不适合临时急单。

3. **Recognition / service awards**
   - 对应 service awards、safety awards、achievement awards。
   - 可用刻字金属笔、金属纪念件、桌面摆件、custom metal keepsakes 切入。

4. **Drinkware premium upgrade**
   - 官网已有 drinkware 类目。
   - Wischos 可补充 stainless / titanium drinkware 的高质感版本，但北美 drinkware 竞争强，作为次级角度。
