## 核心思维转变（料神精髓 → Wischos 翻译）

| 料神原则 | Wischos 落地解读 |
|---------|----------------|
| 找到真正进口的公司，不是零售商 | 找有实际采购需求+预算的：promo distributor（有目录）/ 终端企业 HR/Procurement / awards 公司 |
| 认真研究客户再写信 | 用客户官网/Facebook/LinkedIn 的具体细节做 hook，证明不是群发 |
| 不暴露工厂信息 | 对外只用 Wischos 信息；发货单头不写工厂；交期留缓冲 |
| 同行比价后再报价 | 先查目标国零售价 → 反推买家利润空间 → 定报价策略 |
| 没必要做 pricelist | 维持"Price on request"策略；针对客户需求定制报价，不发通用价目表 |

## Step 3：客户网站分析（深读，不是扫描）

### 3.1 官网分析清单（7个维度）

**① 产品分类信号**
- 产品分类多而杂 → 综合分销商，带货能力强，价格敏感度中等
- 产品分类少但专精（如专做 awards + recognition）→ 专业客户，价格敏感度可能较高，但对品质更挑剔
- **Wischos 关注**：有无金属类？档次如何？有无空白品类可以补？

**② About Us 提炼**
- 角色（distributor / supplier / end-buyer service）
- 成立年份（越老越稳定，新公司可能更灵活）
- 服务的客户类型（corporate / SMB / government）
- 服务的行业（科技/金融/矿业 → 采购力强）
- 进口信号："we source from Asia" / "imported" / "overseas manufacturers"

**③ 服务模式（关键兼容性信号）**
- ✅ 兼容：`planned projects` / `annual programs` / `catalog orders` / `bulk orders`
- ❌ 不兼容：`same-day` / `rush orders` / `local fulfillment within 24 hours`（海运/空运无法满足）

**④ 定价档次信号**
- ✅ 兼容：`premium` / `curated` / `quality-first` / `executive gifts` / `luxury`
- ⚠️ 风险：`cheapest` / `budget` / `value` / `best price guaranteed`（会陷入价格战）

**⑤ 个性化技术能力**
- Fiber Laser 雕刻 → 可供 blank 金属件，他们自己打标
- UV Flatbed 印刷 → 可供大平面金属件（如鼠标垫/立牌）
- 无设备 → 需要 Wischos 提供全套定制件（Logo 预先刻好）
- 技术能力影响合作模式：有设备的买 blank，没设备的买完成品

**⑥ 客户组合 / 案例**
- 官网 Clients / Portfolio / Case Studies → 看他们服务哪些公司
- 大企业客户 → 采购量大，但决策链长
- 本地中小企业 → 采购量小，但决策快

**⑦ 地域 / 本地化限制**
- 明确 "Canadian-made" / "Australian-made" / "locally sourced" → 直接排除
- 无产地限制 → 绿灯

### 3.2 下载客户 Catalog（了解产品线的捷径）

```
方法1（最直接）：site:域名 filetype:pdf
方法2：site:域名 catalog OR brochure OR "product guide"
方法3：site:域名 inurl:pdf
方法4：直接 Google：公司名 2025 catalog filetype:pdf
```

**分析 Catalog 的重点：**
- 金属类产品有多少？档次如何（材质/工艺/包装）？
- 是否有 blank 件（无 logo 版本）
- 当前金属产品的价格段（推算他们的采购预算）
- 哪些场景（awards / desk / drinkware）→ 对应 Wischos 产品线

### 3.3 客户 B2B 足迹检查（他们在哪发过采购需求）

```
Google：alibaba.com + "公司名"
→ 检查该公司是否在阿里发过询价/合作记录

Google：made-in-china.com + "公司名"
→ 同上

Google："公司名" + "send me pricelist" OR "looking for supplier"
→ 公开论坛/行业网站上的采购帖

Google："公司名" + site:linkedin.com
→ 看有无采购相关帖子
```

**判断意义：**
- 有 B2B 足迹 → 正在主动找供应商，接受度高
- 无足迹 → 可能靠现有供应商体系，需更强切入理由
- 足迹中有竞品 → 了解他们目前的供应链，找差异化切入点

### 3.4 判断母子品牌关系

```
工具：站长工具（chinaz.com）→ 输入域名查友情链接
方法：Google "公司名" -域名 site:.com.au
→ 检查是否只是某母公司的子品牌网站（子品牌通常无独立采购权）
```

## Step 4：决策人定位 + 联系方式获取

### 4.1 角色优先级（Wischos 版）

| 角色 | 决策力 | 外展策略 |
|------|--------|---------|
| Owner / Founder（小公司） | ★★★★★ | 直接谈供应商合作，一步到位 |
| Procurement / Sourcing Manager | ★★★★★ | 直接谈供货方案 |
| Sales Manager（管多客户） | ★★★★ | 帮她赢得客户项目（让她的客户更好满意） |
| Category Manager（分销商） | ★★★★ | 展示金属类目的新机会 |
| Brand Manager / HR（终端买家） | ★★★ | 需确认决策链，可能要到 Procurement |
| Marketing / Coordinator | ★ | 无采购决策权，不要作为主要联系人 |

### 4.2 邮箱挖掘（多层次方法）

**层次 1：官网直接获取**
```
WebFetch: 官网 Contact / About / Footer 页面
提取所有 mailto: 链接和明文邮箱
```

**层次 2：Google 搜索**
```
"联系人姓名" "公司域名" email
site:公司域名 "@"
"公司名" contact email
```

**层次 3：Whois 查域名注册人**
```
工具：whois.domaintools.com / whois.chinaz.com
→ 输入域名，查注册人姓名和注册邮箱
→ 小公司创始人常用个人邮箱注册域名
```

**层次 4：Wayback Machine 查历史**
```
工具：web.archive.org
→ 输入域名，选过去时间点（3-5年前）
→ 旧版网站可能有已隐藏的员工邮箱
→ 组合搜索：Mobile Fun owner founder mail（公司名+职位+mail）
```

**层次 5：源码挖邮箱**
```
方法：
1. 进目标公司官网 Contact 页面
2. 右键 → 查看页面源代码（Ctrl+U）
3. Ctrl+F 搜索："@" 或 "mailto:"
→ 70-80% 概率能找到隐藏邮箱（尤其表单背后）
```

**层次 6：邮箱格式推断**
```
工具：email-format.com
→ 输入公司域名 → 查该公司已知的邮箱格式（如 firstname.lastname@ 或 firstlast@）
→ 有一个员工邮箱 → 按格式推断决策人邮箱
常见格式：
  firstname@domain.com
  first.last@domain.com
  firstnamelastname@domain.com
  f.last@domain.com
```

**层次 7：LinkedIn + ZOOMINFO**
```
LinkedIn：搜 "公司名" "采购相关职位"
ZOOMINFO：输入公司名 → 查员工联系方式（免费额度有限）
RocketReach / Hunter.io：输入域名找邮箱（有免费额度）
```

**找不到时的备用话术（LinkedIn 通过后）：**
> "Happy to send over a few specs — easiest by email. What's the best address?"

### 4.3 邮箱验证（发信前必做）

**工具（免费）：**
```
verify-email.org — 输入邮箱验证真实性
mailtester.com — 测试邮箱是否存在
```

## Step 5：客户深度背景研究（报价前的10问）

### 5.1 报价前必回答的10个问题

在报任何价格前，这10个问题越多答出，报价质量越高：

1. **客户是否专业做礼品/周边类业务？**  
   → 官网产品分类、About 页面、LinkedIn 简介

2. **之前是否进口过金属礼品？从哪里进的？**  
   → 海关数据（importyeti / customs.report）、LinkedIn B2B 足迹

3. **当前金属类供应商是谁？产品在什么档次？**  
   → 海关数据 + Catalog 分析 + alibaba 足迹

4. **客户潜力有多大？年采购规模约多少？**  
   → 员工数、客户群、订单规模（Google Maps 评论 / LinkedIn 公司信息）

5. **目标国市场金属礼品的当地零售价是多少？**  
   → 详见 Step 6（零售价调研方法）

6. **同类客户典型采购量大概多少？**  
   → 行业经验 + 海关数据平均采购量

7. **竞争对手（其他中国供应商）可能报什么价？**  
   → 1688.com 同品参考 + alibaba.com 同品报价

8. **适合目标市场的包装方式是什么？**  
   → AU/UK/CA 市场对 retail-ready packaging 要求高；需问客户（gift box / white label / no packaging）

9. **有哪些规格细节可能影响成本？**  
   → 材质（黄铜 vs 钛 vs 不锈钢）/ logo 工艺（激光 vs 印刷 vs 填漆）/ 包装方式

10. **我的报价在国内同行里算什么水平？**  
    → Wischos FOB 区间 $18–50/套（×2.3倍加价，成本 $10–24/套）；确认不是全行最贵也不是最便宜

### 5.2 询盘真实性判断

**4个快速过滤问题：**
1. 询盘内容是否与金属礼品有关？（毫不相关 → 跳过）
2. 是否同行在套价？（只问价不问细节，附 SKYPE 账号 → 警惕）
3. 是否钓鱼邮件 / 欺诈？（要求预付款 / 西联汇款 / 海外转账 → 拒绝）
4. 询盘质量：
   - **明确型**：有产品规格/数量/交期 → 直接推进
   - **不明确型**：无细节 → 先问3个问题（见下）

**不明确型询盘先问3个问题：**
```
1. "FOB or CIF? Which port do you usually ship to?"
   → 判断供应商地区偏好、是否有中间商
2. "For branded corporate gifts, what's the main product category you're looking for?"
   → 了解需求范围，避免报错方向
3. "For this type of gift, what's the typical quantity and lead time you're working with?"
   → 判断是否符合 Wischos MOQ（100起），交期是否可行
```

## Step 6：目标国零售价调研（校准报价空间）

**用途：** 了解产品在当地市场的零售价，反推买家能接受的采购价（通常为零售价的 30–50%）。

### 6.1 各市场主要查价渠道

**加拿大：**
```

```

**英国：**
```

查询格式：Online store + price + 产品英文名 + site:.co.uk
```

**新加坡：**

### 6.2 零售价 → 采购价逻辑推算

```
目标国零售价 ÷ 2.5 ≈ 当地批发/采购价
当地采购价 × 0.6–0.7 ≈ 进口 FOB 价（含运费后合理区间）

示例：
澳大利亚某金属礼品套装零售 AUD 120（约 USD 80）
→ 批发价约 USD 32
→ 进口 FOB 约 USD 20–24
→ Wischos WGS-005/008 FOB $28–35/套 → 在合理范围内
```

### 6.3 eBay 二手价 / 品牌售价参考

```
ebay.com.au + 公司名（检查是否在eBay有卖相同产品，判断零售定价）
eBay + 产品类型 + 目标国 + 筛选"sold items"（已售价才有意义）
```

## Step 7：开发信写法（料神原则 → Wischos 版本）

### 7.1 核心原则

1. **找对的人**：找有采购决策权的人，不是 Marketing / Admin
2. **证明做过功课**：第一句话用客户的具体业务细节
3. **卖机会，不卖产品目录**：给方向，不给 pricelist
4. **透明身份**：`I source custom metal gifts from manufacturers in China`，不冒充工厂

### 7.2 LinkedIn 邀请（≤300 chars）

**结构：[钩子] + [我是谁/做什么] + [连接请求]**

```
钩子来源优先级：
1. 联系人近30天LinkedIn帖子内容
2. 公司官网/Instagram 近期动态
3. 行业共鸣（"Saw you work a lot with tech companies..."）
4. 具体产品线（"Noticed your metal awards range — I supply blank writing sets for engraving"）
```

**禁止词**：really / I'd love to / certainly / just wanted to / amazing / incredible

### 7.3 Cold Email 结构

**Subject（具体到产品+场景，不宽泛）：**
```
❌ "Metal corporate gifts from China"
❌ "New supplier introduction"
✅ "Brass pen blanks for your awards line — MOQ 100"
✅ "Metal executive gift sets for Q4 onboarding programs"
✅ "[客户公司名] — premium metal inserts for your gift hampers"
```

**Body 四段结构：**
```
第1段（1-2句）：他们的具体业务 + 我做什么
"I noticed [公司名] runs a strong awards and recognition line for [行业客户]. 
I source custom metal writing sets and desk accessories from manufacturers in China."

第2段（3 bullets，不超过3类产品）：
- 具体产品 + 场景（不是全目录）
"• Precision-weighted ball pens in brass and titanium — desk-ready, laser-engravable
• Metal desk accessory sets (pen holders, letter openers, stands) — corporate onboarding and year-end
• EDC carry items (key organisers, carabiners) — outdoor and team recognition programs"

第3段（合作模式互补）：
"Given your existing personalisation capability, I'd supply the blank metalwork — you handle the branding. 
FOB from Shenzhen, typically 25–35 days. MOQ 100 sets."

第4段（一个行动请求，二选一）：
"Happy to send a PDF spec sheet or a sample pack (I cover postage). 
Which would be more useful?"
```

### 7.4 异议预案（Wischos 专属版）

| 异议 | 回应策略 |
|------|---------|
| "We already have a supplier" | "Not looking to replace them — just fill the gaps. Happy to be a backup for metal-specific items they don't carry." |
| "MOQ is too high" | "Standard is 100 sets — for a first order, I can work with 50 pieces on one SKU to test." |
| "Lead time from China is too long" | "Air freight is 7–10 days door-to-door. For repeat orders, I keep commonly ordered items on a short reorder cycle." |
| "We source locally / Canadian-made only" | "Totally understood — if that changes, I'd be happy to reconnect." (graceful exit) |
| "Send me a pricelist" | "I'd rather put together a few options based on your specific brief — it'll be more useful than a generic list. Can you tell me the occasion and quantity?" |
| "We don't import directly" | "That's fine — if you point me to the right person who handles sourcing, I can follow up with them." |
| "Too expensive" | "That's fair feedback. Which end of the range was you comparing against? I may be able to adjust the spec." |

## Step 8：产品知识体系（外贸实操层）

### 8.1 各市场规格偏好（已调研结论）

| 市场 | 偏好 | 注意点 |
|------|------|--------|
| 澳大利亚 | 实用耐用，铝/不锈钢受欢迎 | 环保包装加分；不喜过度奢华 |
| 加拿大 | 偏实用+功能，EDC/户外礼品热 | Rush order 要求高，但高价值客户更重视定制 |
| 英国 | 精工质感，黄铜/铜受认可 | 对价格敏感但对工艺有要求 |
| 新加坡 | 国际化，高档商务礼品受欢迎 | 礼品文化强，套件更受欢迎 |
| 德国 | 功能性+品质，不喜浮夸 | REACH/RoHS 合规敏感 |

### 8.2 成本逆推（Wischos 专用）

```
工厂报价 × 2.3 = FOB 含加价
FOB × 1.05–1.1 = CIF（加运费保险，AU约 +$2/套）
客户采购价目标 = 他们零售价的 40–50%

示例（WGS-005 Executive Set）：
工厂成本 ~$12/套 → FOB $28 → CIF AU ~$30
客户AU零售目标 ~AUD 100（~USD 67）
→ 客户采购预算约 $30–35/套 ✅ 在范围内
```

### 8.3 10 个规格/包装问题（每个客户都应答）

1. 该客户所在国家/行业，常用什么包装方式（礼盒/白盒/零散）？
2. 该场景的典型规格是什么（材质/颜色/印刷工艺）？
3. 他们的客户（终端）会怎么使用这个产品？
4. 此类产品在当地市场有没有知名品牌版本？他们怎么卖的？
5. 哪些规格对客户成本有重大影响（材质选择、工艺等）？
6. 哪些规格可以先不报，留谈判空间？
7. 哪些规格 Wischos 有现货，哪些需要定制开发？
8. 目标国对包装/材质有特殊法规要求吗（如澳大利亚食品接触、EU REACH）？
9. 适合做 blank（无 logo）供货，还是完成品（logo 预制好）供货？
10. 对方有没有电子版 logo 文件 + 品牌色号？

## Step 10：报价策略与交期保护

### 10.1 报价原则

- **不发通用 pricelist**：针对客户具体需求定制报价，每次展示专业性
- **报 FOB 深圳/广州**，可附一个 CIF 参考价（含运费保险到目标港）
- **报价有效期 30 天**（原材料价格有波动）
- **数量梯度**：报 100 / 300 / 500 件三档，引导客户往上走
- **首次报价略高于底线**：为谈判留空间（"price can be discussed based on quantity"）

### 10.2 报价前确认清单

```
□ 产品规格是否明确（材质/尺寸/工艺/包装）？
□ 数量是否确认？
□ 目标国零售价已查，报价利润空间合理？
□ 工厂交期已确认（不是猜测）？
□ 是否需要问清楚 Incoterm 偏好（FOB vs CIF vs DDP）？
□ 样品已寄且客户认可规格？（否则先寄样再报正式价）
```

### 10.3 供应商保密操作（SOHO 核心保护）

**发货文件规范：**
- 发货单、装箱单、Invoice 头部 **只用 Wischos 信息**
- 不露工厂名称、工厂地址、工厂联系方式
- 如需产地证（CO），用"China"，不写具体城市/工厂

**交期管理：**
- 工厂实际交期 → 对客户说的交期 = 工厂交期 + 5–7 天缓冲
- 例：工厂说 25 天 → 告知客户 30–35 天
- 分批交货：工厂提前完成一部分 → 可告知客户可以分批出

**与工厂沟通规范：**
- 不引荐客户直接联系工厂
- 工厂样品/文件上有工厂信息 → 发给客户前删除或替换
- 长期客户关系建立前，工厂跟客户的任何接触都要通过 Wischos
